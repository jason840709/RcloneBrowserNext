# Rclone Browser Next 0.4.0：介面驗證

## 結果與範圍

正式 `Resources/Web/index.html`、`app.js`、`style.css` 以 `file://` 載入，完整套件於 **2026-10-20 通過 62 / 62 項 Playwright 測試**，耗時約 **1 分鐘**；沒有略過、失敗或重試後才通過的案例。

完整套件後，最後補齊比較方式的三語說明，並修正尚未發布正式版本時的 App 更新提示。重新建置後，針對這些變更和 production bundle 的 **3 / 3 項回歸通過**，於 **2026-10-20T06:09:54.115Z** 開始，耗時 **7.9 秒**。這 3 項包含全部 7 種比較說明 × 三語、滑鼠與鍵盤操作、1060 × 680 邊界，以及 available/current/unpublished 更新分支；未發布狀態在三語均沒有下載頁按鈕或下載新版提示。TypeScript 型別檢查與 Vite 正式建置皆通過。

這份報告的範圍是介面、狀態管理及原生橋接訊息。測試端替代 macOS host 回應，沒有連接使用者帳號，也沒有把示例工作當成真實的 NAS 或雲端傳輸。Swift Core、更新器與原生程式的驗證另見專案主驗證報告。

## 0.4 修正與驗證

| 項目 | 介面行為與驗證 |
| --- | --- |
| 配色與層次 | 四主題以中性灰、白作背景，紫或藍只作重點色。新安裝預設黑紫；保留既有手動選擇。工具列、作用中的面板、欄位標題與主要操作分層。 |
| 分頁與邊框 | 面板分頁外框有實際內距，未與面板邊界重疊。欄位只畫一條 1 px 細分隔，保留至少 12 px 的透明拖曳區。最後一欄拖曳區不溢出捲動範圍。 |

| 記住 | 主介面保存左右位置、方向、操作及完整傳輸選項，重開恢復但不開始傳輸。ⓘ 明確說明檔案勾選不納入；需要保留選取範圍時存為作業。 |
| 啟動位置 | 設定可分別編輯左右啟動資料夾；已有記住的工作環境時，同步更新其位置，避免修改被優先順序蓋掉。忘記環境同時清除新、舊兩種啟動位置。 |
| 作業清單 | 改為緊湊列表，提供明顯的 Dry Run、執行、編輯、刪除入口。新建和編輯使用完整表單，含來源、目標、方向、操作、勾選、比較、略過、同步刪除、篩選、速度、逾時與額外參數。 |
| 作業保存 | 編輯保留作業 ID、選取及完整選項，另有另存新作業。目的地變動保留選取；來源或方向變動會清除舊選取並明確提醒。編輯和保存從不自動執行。 |
| Dry Run | 主介面和作業列表均明確顯示 Dry Run。按鈕送出真正的 `startTransfer` 請求並設 `dryRun: true`；執行使用同一保存快照但設為 false。不是只顯示命令預覽。 |
| 比較方式 | 各模式的 ⓘ 說明用途、讀取成本與漏判限制。預設方式指出時間差可能觸發兩端內容雜湊，SMB 掛載時可能走網路；只比大小、只比時間及只比雜湊各有獨立說明。 |
| NAS 比較 | 名稱為「大小與修改時間（不計算本機雜湊）」，送出 `comparison: default`、`localHashPolicy: none`，由 Core 對應 `--local-hashes=none`。只停用 local 後端雜湊，包含 SMB 掛載位置，不泛指所有遠端。提示說明容許差應依時間精度設定，且相同大小／時間的內容變更無法偵測。 |
| 位置選單 | 使用原生回傳的主資料夾、桌面、文件、下載、圖片、音樂、影片、Volumes 與掛載位置。分開本機、NAS／伺服器、雲端與其他連線；不把 WebDAV、S3 或包裝型後端武斷歸為 NAS 或雲端。正式程式沒有寫死帳號名稱。 |
| 同時工作數 | 新預設為不限（0）；可選限制數字。工作歷史保留最近 200 筆已結束工作，活動與排隊工作保留。 |
| rclone 網路設定 | 代理之外，可設 IP 模式／自訂 IP、連線與讀寫逾時、每秒請求上限、突發請求數、User-Agent、HTTP/2。自訂 IP 先填有效值再原子提交；快速修改的部分更新依序保存，不互相覆蓋。個別傳輸的空白逾時表示繼承。 |
| 更新與關於 | 選單分開 rclone 引擎與 Rclone Next 更新，另有原生關於視窗。App 尚未發布正式版本時，三語均提示稍後檢查，只有關閉按鈕；已發布版本才提供正式頁。 |

## 保留的 0.3 行為

rclone 位置仍使用單一、可理解的設定入口；選資料夾或執行檔後立即保存、重新偵測。更新檢查會等候先前保存完成，舊 bootstrap 快照不能覆蓋較新設定。保存遭拒會復原並可再次操作，不需重啟。

保留 copy／move／sync、同步刪除時機與上限、原版比較組合、篩選和重試、額外參數、帳號設定 Config、最多 12 個面板分頁、Finder 拖放準備、目錄樹、CSV/TXT 匯出、公開連結、掛載、串流和原生剪貼簿。Move 搭配略過較新檔案的不安全組合仍阻擋，並說明原因。輔助程序終止事件不會被過時的 running 快照覆蓋。

## 視覺、字體與鍵盤

24 組主畫面測試涵蓋繁體中文、英文、日文 × 四配色 × 1060 × 680 與 1440 × 900。另有三語完整作業表單和網路設定的小視窗檢查。1060 × 680 與原生視窗最小內容尺寸一致。確認操作可到達、不被遮住、頁面無水平溢出、日期含西元年、進度與傳輸統計更新正確。

使用系統字體，主文字 14 px；保留使用者提供的 **v2 small SVG** 作為左上圖示及網頁圖示，逐位元比對相同。App 的 `.icns` 由原生建置步驟管理。

ⓘ 支援 hover、focus、點擊固定、Escape 和點擊外部關閉，內容以輔助說明關聯控制項。鍵盤操作、選單方向鍵、設定快捷鍵與欄寬方向鍵均保留。減少動態效果時關閉按鈕與對話框縮放；檔案清單與欄寬拖曳沒有額外動畫。

從正式頁面的 computed CSS 擷取色彩，**80 / 80** 個色對通過指定門檻：一般文字最低 **4.90:1**，控制項邊界最低 **3.50:1**。範圍包含主文字、次要文字、預留文字、主按鈕狀態、選取文字及提示訊息；停用控制項不列入。這不是完整 WCAG 或 VoiceOver 稽核。

設計取捨參考 Apple 的 [Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables)、[Offering help](https://developer.apple.com/design/human-interface-guidelines/offering-help) 與 [Color](https://developer.apple.com/design/human-interface-guidelines/color)。比較旗標已核對 rclone v1.75.2 的 [官方文件](https://github.com/rclone/rclone/blob/v1.75.2/docs/content/docs.md)、[operations.go](https://github.com/rclone/rclone/blob/v1.75.2/fs/operations/operations.go) 和 [local 後端文件](https://github.com/rclone/rclone/blob/v1.75.2/docs/content/local.md)。

## 產物與證據

`Resources/Web` 共 **681,354 bytes**，包含 JavaScript、CSS、HTML、v2 SVG 與第三方授權聲明。沒有打包 Chrome、Node、fixture、字型或開發快取；正常 Mac 建置直接使用已建資源。

`verification.json` 記錄版本、測試摘要、正式檔案 SHA-256、大小及截圖 SHA-256。內部證據位於 `WebSource/.build-cache/qa04`；完整套件截圖在 `playwright` 子目錄，最後 3 項回歸記錄在 `final-targeted-results.json`。`render-previews.ts` 可重現四主題兩尺寸、設定、傳輸、作業與 tooltip 截圖。

所有預覽只使用刻意虛構的測試資料；未把使用者真實 Mac 截圖、帳號或路徑複製到正式資源或公開 fixture。圖片作內部審查證據，不代表真實 NAS 或雲端傳輸。

## 尚未在此環境驗證

Linux Chrome 的 `file://` 執行不能取代 macOS 的 AppKit／WKWebView 實機驗證。本報告沒有驗證 Gatekeeper、簽章、公證、原生檔案選擇器、Finder 系統拖放、雲端登入、實體 SMB 網路磁碟、FUSE 掛載或實際播放器。介面測試通過不能推論這些實機項目已完成。
