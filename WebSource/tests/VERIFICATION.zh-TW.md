# Rclone Browser Next 0.5.0：介面驗證

## 結果與範圍

正式 `Resources/Web/index.html`、`app.js`、`style.css` 以 `file://` 載入，測試的是交付用的 production bundle。TypeScript 型別檢查與 Vite 正式建置均通過。

本輪在 **2026-10-20 共驗證 86 個不同案例**，由兩次執行組成：

| 執行 | 開始時間（UTC） | 結果 | 耗時 |
| --- | --- | --- | --- |
| 首次完整套件，81 項 | 09:12:47.117 | 78 通過，3 項舊 assertion 不符新預設／fixture | 99.2 秒 |
| 更正 assertion 後的指定回歸，8 項 | 09:15:50.606 | 8 通過，0 失敗 | 16.6 秒 |

第二次包含第一次的 3 項更正案例，以及 5 項新增案例。因此唯一案例數為 **78 + 3 + 5 = 86**；不將重複執行的 3 項再次計數，也不把第一次執行改寫為全部通過。兩次均無略過或 flaky 案例。兩次之間沒有修改正式程式碼、重新建置或替換 production bundle。

三項更正如下：

| 測試名稱 | 更正內容 |
| --- | --- |
| comparison tips work with hover, focus, click and Escape without dismissing the dialog | 初始比較方式已改成不計算本機雜湊，tooltip assertion 改為對應的 `comparisonNASHint`，不再期待舊的 `comparisonDefaultHint`。 |

另外新增的 5 項覆蓋：已有通知時快速儲存並關閉作業編輯器、新操作選單的鍵盤初始焦點，以及繁中／英文／日文三種 NAS 到雲端的建議說明。

這份報告的範圍是介面、狀態管理及原生橋接訊息。測試端替代 macOS host 回應，沒有連接使用者帳號，也沒有把示例工作當成真實 NAS 或雲端傳輸。Swift Core、更新器與原生程式的驗證另見專案主驗證報告。

## 本輪修正與驗證

| 項目 | 行為及核對結果 |
| --- | --- |
| 錯誤區塊 | 目錄讀取錯誤的圖示、標題、診斷與重試按鈕全部位於同一張有背景的卡片內。錯誤狀態不再延續檔案列表斑馬紋；長訊息可在卡片內捲動，未超出面板。重試成功恢復檔案清單。 |
| 空作業 | 尚未儲存作業時只顯示提示卡、新增與匯入入口；不存在假資料列、選取 footer、執行、Dry Run、編輯、刪除或匯出按鈕。新增後出現正常操作；刪除最後一筆後恢復空狀態。 |
| 暫時通知 | 以獨立浮層呈現，不改變左右面板位置或尺寸。預設 5 秒收起，可手動關閉；滑鼠停留或鍵盤焦點在通知內時保留閱讀時間。進出使用透明度／位移，減少動態效果時只淡入淡出。 |
| 通知競態 | 重複關閉會取消舊的結束計時器。連續通知刷新壽命；主畫面通知使用穩定的 body portal，作業編輯器關閉不會把新通知一起移除。 |
| 單向同步 | 顯示「以來源為準更新目標，刪除目標多出的檔案。來源不變。」詳細說明界定單向同步、篩選範圍及略過規則；沒有引入雙向同步。 |
| 新預設 | 比較為大小與修改時間、不計算本機雜湊；刪除時機為傳輸時；最多刪除數不限。Core 對應的 options 為 `comparison: default`、`localHashPolicy: none`、`deleteMode: during`、`maxDelete: -1`。載入既有作業或記住的環境仍保留其完整設定。 |
| 常用方案 | 操作方式選單先列本機到 NAS、NAS 到雲端、本機到雲端，再列複製、同步、移動。套用方案保留左右位置與方向，重設完整傳輸選項，清除略過既有／較新檔案規則，設成單向同步，但不自動開始。 |
| 方案參數 | 本機到 NAS 為 1 個傳輸、10 個檢查，另關閉單檔平行區段；NAS 到雲端為 1／10，本機到雲端為 4／8。減少同時讀寫的檔案數不等於保證避免磁碟碎片。 |
| 隱藏與復原 | 小叉只隱藏內建方案，儲存在 `hiddenBuiltinPresets`；不刪除或改動已套用的傳輸設定。重啟仍維持隱藏。傳輸選項的復原按鈕重新顯示內建項目。 |
| 鍵盤選單 | 打開操作選單後焦點放在目前已選的操作，不會落到隱藏方案的叉。方向鍵、Home／End、Escape 和外部點擊可操作選單。 |
| NAS 建議 | 依左右位置識別本機、掛載 NAS、NAS remote 與雲端，顯示適用建議。三語說明區分「避免不必要的比對讀取」與「變更檔案仍需經過目前這台 Mac 傳輸」。 |
| 比較說明 | 短句說明加上 ⓘ 詳細說明，涵蓋各種 Compare／Skip／刪除／篩選／重試／網路逾時的用途與取捨。只比大小是時間資訊不可靠時的折衷；不把它當成一般 NAS 首選。 |
| 雜湊限制 | 停用 local 雜湊可避免讀取本機或 SMB 掛載 NAS 內容來算 hash，但也不提供這一端的內容 hash 校驗。大小與修改時間都相同的內容變更仍可能漏判。原生 SMB 後端不提供 hash，與 SMB 掛載的 local 後端有所區別。 |
| macOS 排除項目 | 內建方案排除 `.DS_Store`、`._*`、`.Spotlight-V100/**`、`.Trashes/**`、`.fseventsd/**`、`.TemporaryItems/**`。說明指出 `._*` 可能含 AppleDouble 資源／中繼資料，可按需求移除規則；不排除所有隱藏檔或所有 `.tmp`。 |
| 面板垂直順序 | 第一列為左右側及來源／目標，第二列為資料夾分頁，第三列合併位置選單、上一頁、下一頁、上一層與路徑。1060 寬下仍保留角色標籤，沒有重複的「目前資料夾」列。 |
| 連動分頁 | 作用中分頁與下方路徑列共用底色且相接；非作用中分頁沒有外框。深／淺色、1060／1440 寬均核對邊界及選取狀態。 |
| 返回與前進 | 各分頁有獨立、有上限的 back／forward 歷史；返回後新導航會清除該分頁的前進路徑，不影響其他分頁。支援原生滑鼠側鍵事件、未啟用原生側鍵時的 DOM fallback，以及 Cmd／Ctrl + `[`／`]`。 |
| 側鍵路由 | 游標所在面板優先，否則使用作用中面板。原生旗標防止 DOM 事件重複導航；有對話框或正在輸入路徑時，相關快捷鍵不會改變正在編輯的內容。 |
| 速度與時間 | 呈現後端最近最多 60 秒的平均處理位元組速率與粗估剩餘時間；工作結束後保留全程平均。ⓘ 說明本機快速複製／伺服器端複製的數值不一定等於網路流量，ETA 依目前已發現的總量估算。 |
| 細微進度 | 百分比顯示一位小數；仍在執行時最多顯示 99.9%，完成後才顯示 100.0%。總位元組數為零的工作改以檔案數比例顯示；檔案數統計使用「檔案數量」標籤。 |

## 大清單與傳輸更新的負擔

兩個面板各載入 **100,000 筆虛構檔案**。檔案清單維持虛擬化，兩側合計實際渲染的資料列少於 100 個。

在目錄與選取未改變時，連續送入 **25 個進度事件**：

- 沒有重新對 100,000 筆清單執行完整的 `map`、`filter` 或 `sort`。
- 沒有額外發出目錄列表請求。
- 25 個更新的測試瀏覽器經過時間約 **679.1 ms**。

這是避免每秒進度更新反覆掃描整張清單的回歸保護，不是 macOS CPU 使用率或 NAS 網路滿速基準測試；不能據此保證某一台 Mac 或 NAS 的實際傳輸速度。

## 保留的功能與版面覆蓋

原有 62 項案例在本輪套件中持續驗證：原生 IPC 與跳脫檔名、rclone 位置即時儲存／刷新、更新與重試、設定部分更新排序與 rollback、語言跟隨系統、記住工作環境、完整作業新增／編輯／另存、Dry Run／Run、來源變更時處理勾選範圍、NAS／雲端／本機目錄分類、網路設定、欄位調整與持久保存、全寬斑馬紋、設定與 About／引擎更新／App 更新分離、檔案工具、拖放準備，以及鍵盤與減少動態效果。

主畫面測試包含繁體中文、英文、日文 × 四主題 × 1060 × 680／1440 × 900。另有三語完整作業表單、網路設定與比較 tooltip 的小視窗檢查。1060 × 680 與原生視窗最小內容尺寸一致。主題仍使用中性灰／白背景、紫色或藍色重點色，新安裝預設黑紫。

從正式頁面的 computed CSS 擷取色彩，**80／80** 個指定色對通過門檻：一般文字最低 **4.90:1**，控制項邊界最低 **3.50:1**。範圍包括主文字、次要文字、預留文字、主按鈕狀態、選取文字及提示訊息；停用控制項不列入。這不是完整 WCAG 或 VoiceOver 稽核。

保留使用者提供的 v2 SVG 圖示，檔案 SHA-256 與 0.4.0 相同。`.icns` 與原生 App 圖示由原生建置流程管理。設計與技術依據另見專案主文件及官方 [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/) 和 [rclone 文件](https://rclone.org/docs/)。

## 尚未在此環境驗證

Linux Chrome 的 `file://` 執行不能取代 macOS AppKit／WKWebView 實機驗證。本報告沒有驗證實體滑鼠的側鍵、Gatekeeper、簽章、公證、原生檔案選擇器、Finder 系統拖放、雲端登入、實體 SMB 網路磁碟、FUSE 掛載或實際播放器。介面測試通過不能推論這些實機項目已完成。
