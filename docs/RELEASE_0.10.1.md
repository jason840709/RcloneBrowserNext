# Rclone Browser Next 0.10.1

0.10.0 並未單獨發布，本版同時包含 0.10.0 的介面翻新與後續修正。

## 0.10.0 重點回顧

- **傳輸速度更穩定**：改用最近 10 秒計算速度、30 秒估算剩餘時間；等待單一檔案完成期間顯示「等待檔案完成」，不再先掉到 0 再暴增。
- **Mac 介面重新設計**：採用原生 macOS 工具列、對齊 Finder 的 100% 字級與列高、凸起按鈕與內凹輸入框、合併位置與路徑網址列、自動／淺色／深色外觀與統一動畫（詳見 [0.10.0 改版說明](https://github.com/jason840709/RcloneBrowserNext/blob/main/docs/RELEASE_0.10.0.md)）。

## 0.10.1 改進與修正

- **勾選欄跟隨傳輸方向移動**：只有來源窗格會顯示勾選欄，目標窗格不再留白；切換傳輸方向時，勾選欄會以動畫移至新的來源側。
- **修正清單捲不到底**：修正 0.10.0 因容器查詢設在整個窗格，導致非 100% 縮放（如 90%、125%）時捲到底部會往上回彈的問題。
- **「設定已儲存」改為浮動提示**：不再固定佔用設定視窗頂端空間，改為從視窗下方浮現、數秒後自動收起。
- **修正按鈕外觀細節**：移除帳號設定分段按鈕殘留的雙層底色、修正滑鼠懸停變亮範圍，並將工具列「儲存」按鈕圖示從易誤會的下載箭頭改為圖釘。
- **Windows 與 Linux 縮放基準同步**：與 Mac 版一致，100% 改為實際大小（比 0.9.6 的 100% 大約一成；若習慣舊版大小可在設定調為 90%）。
