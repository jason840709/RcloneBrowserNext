# Rclone Browser Next 0.10.1

0.10.0 介面改版後的修正版。傳輸、比對與帳號設定的行為沒有改變。

## 改進

- **勾選欄跟著傳輸方向移動**：只有來源那一側需要勾選檔案，所以只有來源窗格有勾選欄；目的地窗格不再留一欄空白，檔名直接從左邊開始。切換傳輸方向時，原本那側的方框先縮小消失、欄位收起，檔名順勢左移；另一側的檔名往右讓出空間，方框再浮現。

## 修正

- **清單捲不到底**：檔案很多時，用滑鼠滾輪捲到最後會往上彈，停在離底部還有一段的地方。原因是 0.10.0 把整個窗格設成「依寬度調整版面」的容器，WebKit 因此在介面大小不是 100% 時（例如 90%、125%）算錯清單的可見範圍，清單接近底部時一再把捲動位置往回拉。現在只有窗格上方的工具列使用這個設定，清單恢復正常；在 90%、100%、110%、125% 都實測可以一路捲到底。
- **設定已儲存的提示**：原本是一條固定在設定視窗頂端、不會消失的提示，還會把內容往下推。改成浮在視窗下方的提示，幾秒後自動收起，也可以按叉叉關閉。工具視窗裡的成功提示也一起改。
- **分段按鈕重複的底色**：帳號設定的「快速設定／詳細設定」出現兩層底色，是舊版樣式殘留。已移除，現在只有一個會滑動的底塊。
- **滑鼠移過按鈕時亮起的範圍不對**：一般按鈕「滑過變亮」的規則權重太高，蓋過了強調色圓點、分頁、分段按鈕等元件自己的外觀。已降低它的權重，各元件維持自己的樣子。帳號設定裡的展開項目也改用和其他地方相同的箭頭。
- **儲存按鈕的圖示**：原本的「方框加向下箭頭」是 macOS 的下載圖示，容易誤會。改成圖釘（記住目前的工作區）；選單裡「儲存工作區」標圖釘、「儲存為作業」標書籤，和「作業」頁的圖示一致。

## 驗證

- 網頁介面自動化測試全部通過，並新增兩項測試，防止上面的捲動與提示問題再出現。
- 原生測試（Mac 介面、啟動畫面、圖示、完成通知、導航）通過。
- 在實際 App 中，於四種介面大小各捲到底三次，沒有一次被拉回。
