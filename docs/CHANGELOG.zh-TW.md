# 修改記錄

## 0.5.0

### 介面與瀏覽

- 目錄錯誤的圖示、標題、診斷與重試按鈕改放同一張提示卡片，避免斑馬紋穿過訊息。
- 未儲存作業時隱藏作業列表與執行工具列，只保留新增／匯入入口及提示。
- 短暫通知改成懸浮視窗，手動關閉或約 5 秒自動收起；出入有動畫，不推動版面，支援減少動態效果。
- 面板順序改為左右／角色、分頁、合併位置與路徑列；選中的分頁與內容底色連在一起。
- 每個分頁加入真正的返回／前進歷史，支援滑鼠側鍵與 Command＋`[`／`]`。

### 同步與常用方案

- 明確說明同步以來源為準，只修改目標；仍受選取、排除及比較方式影響。
- 操作選單新增電腦到 NAS、NAS 到雲端、電腦到雲端方案；可隱藏與還原，套用後不自動執行。
- 電腦到 NAS 採單一檔案傳輸、10 個檢查工作、停用單檔多路傳輸，避免只設 transfers=1 卻仍分段並行。
- 新起始值改為大小與修改時間／不計算本機雜湊、傳輸時刪除、不限刪除數。
- 提供各種比較方式、略過條件、刪除、篩選與效能選項的短說明及詳細 ⓘ 提示，補上 NAS 情境與限制。
- 方案只排除具體的 Mac 暫存／中繼資料名稱，保留一般隱藏檔；說明 AppleDouble 排除的代價。

### 速度與進度

- 使用既有每秒 JSON 的累計容量估算最近 60 秒速度，處理系統快速複製可能不回報 speed／eta 的情形。
- 完成後保留整次平均速度，不再清成零；重啟後仍可查看歷史工作的平均速度。
- 百分比顯示一位小數，數量欄改名為「檔案數量」。
- 估算使用固定上限的數值樣本，不增加檔案掃描、雜湊或額外傳輸程序。

### 升級資料

設定 schema 升為 5，記住隱藏的方案，遷移舊全域預設值。已儲存作業、工作歷史及記住的環境保留原本傳輸選項；舊版省略欄位的保存格式也依舊版預設補齊。這次不因改全域預設而放寬舊作業的刪除上限。

## 0.4.0

### 介面

- 四個主題改成中性灰底搭配紫／藍重點色，預設深紫。
- 調整外框、分頁與文字間距；欄位只顯示一條細分隔線，拖曳區保留足夠寬度。
- 縮窄欄位後，交錯列底色延伸到右側與下方空白區；加粗捲軸。
- 設定名稱調整為「rclone 安裝位置」「預設啟動資料夾」。
- 新增比對方式與重要選項旁的 ⓘ 說明。
- 本機常用資料夾及掛載磁碟加入位置選單，雲端與 NAS／伺服器分組。

### 作業與設定

- Tasks 直接提供 Dry Run、Run、Edit、Delete；儲存與編輯可查看完整傳輸設定。
- 主畫面的 Dry Run 使用明確名稱，與真正執行區分。
- 新增「記住」，保存左右位置、方向與傳輸設定，在下次開啟還原。
- 語言新增跟隨系統；中文系統用繁中，日文用日本語，其餘用 English。
- 移除預設同時 2 個工作的上限，改成不限；可自行設定限制。
- 工作歷史只保留最近 200 筆已結束工作；執行中、排隊及 Tasks 不受影響。
- 網路新增 IPv4／IPv6、來源 IP、逾時、TPS、User-Agent 和 HTTP/2 相容設定。

### 原生功能與發行

- Command＋Q 每次確認，並在確認期間防止新工作插入。
- 關於視窗列出作者 Jason Chen。
- rclone 引擎與 Rclone Next App 各有獨立更新檢查入口。
- App 更新檢查識別 GitHub 正式版、未發布狀態與可重試的失敗；下載頁限制於本專案。
- 補充公開原始碼的建置、功能對照及開發說明；新增 macOS Apple Silicon／Intel CI。

### 升級資料

沿用原本 Application Support 位置，保留 rclone 路徑、帳號設定檔、Tasks 與明確選擇的外觀／語言。舊預設工作上限 2 一次性改成不限；其他非預設限制保留。記住的環境不會在啟動時自動傳輸。

## 0.3.0

建立單一 rclone 位置設定流程、四主題及三語介面；補入原版傳輸選項、NAS 比較、Task JSON 保存、帳號 Config、目錄工具、JSON 進度和本機建置流程。0.4.0 改善這些功能的入口與操作完整性。
