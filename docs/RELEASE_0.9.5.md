# Rclone Browser Next 0.9.5

## 修正同名檔案造成的清單錯亂

某些遠端資料夾會包含同名項目。先前介面以檔名識別畫面列，兩個同名項目會共用同一個識別值；來回切換資料夾時，畫面列可能錯誤沿用、重複或累積，底部項目數卻仍來自正確的清單資料。

0.9.5 為每個顯示項目提供互不衝突的列識別，完整保留同名檔案。資料夾導航、快取回訪、排序、搜尋及重新整理使用一致的列識別方式。這項修正處理畫面更新，不會合併、重新命名或刪除遠端同名檔案。

重新整理仍會清除發起窗格所有深度、分頁與帳號的工作階段快取，再重新讀取目前位置。先前問題發生在畫面列的更新，因此即使重新取得清單，也可能持續顯示錯亂的列。

## 相容性與發布驗證

保留 0.9.4 的各窗格快取、可取消載入、過期回應防護、固定捲軸區，以及既有傳輸與檔案系統行為。Mac、Windows 與 Linux 使用統一的 0.9.5 版本。

新增同名項目的導航回歸案例，使用包含重複名稱及路徑的清單，核對實際顯示列、項目數、快取回訪及強制重新讀取；Chromium 全套與指定 WebKit 回歸都包含此案例。Windows 升級驗證加入已發布的 0.9.4，並保留 0.9.0、0.9.0-r1、0.9.2 與 0.9.3 路徑。
