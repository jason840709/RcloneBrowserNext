# Rclone Browser Next 0.9.5

## 修正同名檔案造成的清單重複與錯亂

部分雲端服務（如 Google Drive）允許同一個資料夾內有多個同名檔案。舊版介面直接以檔名作為畫面列的識別碼（key），遇到同名項目時會因 key 重複，導致來回切換資料夾後畫面列殘留、重複或累積。

0.9.5 為每個顯示項目產生獨立且不衝突的列識別碼，完整保留所有同名檔案，來回切換資料夾、快取回訪、排序、搜尋與重新整理都不再錯亂（此修正僅調整畫面渲染，不會改名或合併遠端檔案）。

詳細排查過程與驗證範圍請見 [問題重現與修正紀錄](DEBUG_0.9.5.zh-TW.md) · [驗證範圍與結果位置](VALIDATION.zh-TW.md) · [0.9.4 功能說明](RELEASE_0.9.4.md)。
