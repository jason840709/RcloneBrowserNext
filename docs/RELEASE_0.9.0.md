# Rclone Browser Next 0.9.0

這一版統一啟動載入畫面尺寸、重整主題排列與工具列按鈕，並簡化主畫面的傳輸說明。

## 更新重點

- **啟動畫面一致**：原生「正在啟動」與網頁「正在讀取 rclone 設定」共用相同的圖示尺寸、字級與縮放比例，切換階段時畫面不再跳動。
- **工具列與外觀排列**：
  - 外觀主題排成三欄兩列：上排淺紫、淺綠、淺藍，下排黑紫、黑綠、黑藍。
  - 設定齒輪移至帳號設定左側；「儲存工作區」與「儲存作業」並排放置並附上 `ⓘ` 說明。
- **傳輸說明更清爽**：統一複製、同步、移動的說明文字；移除「同時傳輸 1／7」與「∞」縮寫，改為只在設定限速時顯示速度上限。
