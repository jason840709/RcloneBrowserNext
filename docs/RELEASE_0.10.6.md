# Rclone Browser Next 0.10.6

- 可在帳號設定中新增「SMB 直連」，填好 NAS 位址與登入資料後，即可選擇共享資料夾，不需要先在 Mac 掛載。
- 位置選單會在 NAS 名稱右側標示「Mac 掛載」或「SMB 直連」，方便辨認目前的連線方式。
- Mac 與 Linux 的 SMB 直連會保留 NAS 的原始檔名，改善部分日文濁音名稱在 Mac 掛載時看得到、卻無法開啟的情況；傳到本機時也會保留特殊引號與全形符號。
- Mac 與 Linux 在本機資料夾之間同步時（包含 Mac 已掛載的 NAS），即使遇到來源讀取錯誤，也會清理其他已確認「來源沒有、目標為空」的資料夾，工作仍會標示同步失敗。清理仍依選取範圍、排除規則與刪除限制執行，預演時只列出結果。
- 修正 Mac 版偶爾在介面已經載入後，仍顯示「畫面未能載入」的問題。
- Mac 版可雙擊視窗頂端的空白處，將視窗放大到螢幕可用範圍；再雙擊一次即可還原大小。
