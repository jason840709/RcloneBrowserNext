# Rclone Browser Next 0.10.6

- 帳號設定新增「SMB 直連」，填好 NAS 位址與帳密即可直接選取共享資料夾，免先在 Mac 掛載。
- 位置選單在 NAS 名稱右側標示「Mac 掛載」或「SMB 直連」，一眼分清連線方式。
- Mac 與 Linux 的 SMB 直連及傳檔回本機時保留原始檔名，解決部分日文濁音、特殊引號與全形符號在 Mac 掛載時無法開啟的問題。
- Mac 與 Linux 本機同步（含已掛載 NAS）遇到來源讀取錯誤時，仍會依選取範圍、排除規則與刪除上限，清理其他已確認「來源沒有、目標為空」的資料夾（該次工作仍標為同步失敗）。
- 修正 Mac 版偶爾在畫面已載入後，仍顯示「畫面未能載入」的問題。
- Mac 版雙擊視窗頂端空白處可放大至螢幕可用範圍，再雙擊一次還原。
