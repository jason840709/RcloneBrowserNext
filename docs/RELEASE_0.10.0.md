# Rclone Browser Next 0.10.0

這一版做兩件事：修正傳輸速度的算法，以及把整個 Mac 介面重新設計成接近 macOS 原生 App 的樣子。傳輸、比對、同步與帳號設定的行為沒有改變。

## 傳輸速度改用最近 10 秒計算

速度欄現在顯示「過去約 10 秒處理的資料量換算成的速度」，剩餘時間用過去約 30 秒的平均估算，數字比較穩，速度改變時也會在 10 秒內反映出來。

0.9.5 以前，速度用最近 60 秒的平均計算，資料量取自 rclone 回報的「已處理資料量」。問題出在某些複製方式：檔案整個複製完，rclone 才一次把這個檔案的大小加進去。複製一個大檔時，已處理資料量會停住好幾十秒，速度就先一路下滑、再歸零，等檔案完成又突然暴增。實際紀錄中，一個 5 GB 的本機複製有 87 秒都停在同一個數字。

這類複製包括：

- 同一個雲端帳號內的複製或移動，由雲端伺服器自己完成；
- 0.9.5 以前 macOS 本機磁碟之間的複製。0.9.6 起已經改用一般複製，會即時回報進度。

現在遇到這種情況，速度欄會顯示「等待檔案完成」，剩餘時間顯示「—」，進度條加上緩慢的光澤表示仍在處理；檔案完成後恢復正常顯示。上傳時資料一段一段送出（例如 Google Drive 每次 8 MB），速度也不會在兩段之間忽高忽低；真正斷線停住時，速度仍會在 10 秒左右降到 0。

## 介面重新設計

完整的設計規則寫在[介面設計規範](DESIGN_SYSTEM.md)。

- **和 Finder 同樣大小**：介面大小 100% 現在等於 macOS 的實際大小。清單文字 13 點、資料夾與檔案圖示 16 點、列高 22 點，和 Finder 的清單一致。舊版的 100% 其實縮小成 0.9 倍，所以字和圖示偏小。介面大小的設定值沒有變，100% 的畫面會比舊版大約一成。
- **原生工具列**：視窗上方改用 macOS 原生工具列，放「檔案、傳輸、作業」切換，以及帳號、儲存、設定按鈕。macOS 26 以後會套用系統的玻璃質感。切換頁面時，選取的底塊會滑到新的頁面，選取中的圖示用強調色。滑鼠停在帳號、儲存、設定按鈕上，0.4 秒就會出現說明。
- **元件分得出主次**：
  - 能按的（按鈕、選單）是往外凸的膠囊，能輸入的（路徑、搜尋、數字）是往內凹的圓角框。
  - 分段控制只有一個滑塊，會在選項之間滑動，未選取的段落沒有底色，不再有兩個橢圓相接的接縫。
  - 位置選單和路徑合成一條網址列；窗格較窄時，搜尋收成放大鏡圖示，點下才展開。
- **少框線、多空間**：左右窗格貼齊視窗、用細線分隔，窗格上方只有一排工具；只有一個分頁時不顯示分頁列（⌘T 開新分頁）。
- **外觀與強調色**：
  - 外觀可選「自動、淺色、深色」，「自動」會跟著 macOS 切換。
  - 強調色保留和 App 圖示一致的紫、綠、藍，是低飽和的色調。用在主要按鈕、勾選框、進度、資料夾圖示、使用中窗格的選取列、連結，以及選取中分頁的圖示上，換主題時看得出差別。
- **文字層級**：頁面標題、對話框標題、區塊標題、內文、說明各有固定的字級與顏色，標題不再比內容小。設定裡每個區塊的標題貼近自己的區塊，和上一個區塊明顯隔開。
- **對話框**：
  - 開啟時背景變暗，Mac 版連工具列也一起變暗。點暗色區域就能關閉，效果等於按「取消」。
  - 傳輸選項改過但還沒套用時，點暗色區域不會關閉，對話框會輕輕彈一下提醒。
  - 對話框打開時，工具列按鈕不再先變暗再變亮。
  - 傳輸選項改成 macOS 的表單排版，分成「一般、篩選、進階」三頁，選項說明在滑鼠停在標籤上時出現。
- **動畫**：所有動畫用同一套時間和曲線：
  - 頁面依方向滑入，設定與選項的分頁依方向滑入。
  - 對話框放大淡入、收起時淡出下沉；選單從按鈕處展開；傳輸佇列收合時高度與箭頭一起變化；新的傳輸從上方滑入；切換淺色或深色時整個視窗淡入新外觀。
  - 開啟「減少動態效果」時，移動與縮放改為淡入淡出，讀取中的轉圈仍會轉動。
- **文字**：統一用語（「預演」、「傳輸」、「作業」、「資料夾」），改寫不夠清楚的說明。

## 相容性

- 設定檔沿用原本的格式，外觀新增「自動」選項；舊版的「跟隨系統」設定會轉成「紫色、自動」。
- Windows 與 Linux 相容版使用同一套網頁介面，但仍由網頁畫出上方工具列。
- 版本號統一為 0.10.0。

## 驗證

本機在 macOS 27.2（Apple Silicon）上完成：

- Swift 核心與原生測試全部通過，包含新增的速度計算測試：一個大檔停住 87 秒、分段上傳、速度改變與真正停住各種情況。
- 用真的 rclone 1.75.2 做限速 25 MB/s 的本機複製，畫面顯示 25.1 MiB/s，剩餘時間與實際相符。
- 在隔離的測試帳號中開啟實際 App，檢查淺色、深色、自動與三種強調色的畫面；頁面切換、分段滑塊、對話框開關、工具列暗幕都用連續擷取逐格確認，並和 Finder 截圖比對文字、圖示與列高。

Windows 與 Linux 相容版沒有在這一版重新建置或測試。
