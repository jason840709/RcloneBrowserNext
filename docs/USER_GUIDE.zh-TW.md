# Rclone Browser Next 0.4.0

作者：**Jason Chen**

Rclone Browser Next 是給 macOS 使用的雙面板 rclone 圖形介面。左右兩邊都能選本機資料夾、雲端或 NAS／伺服器，依指定方向複製、移動或同步。

[English](../README.en.md) · [Mac 建置說明](BUILD_MAC.zh-TW.md) · [功能對照](FEATURE_MATRIX.zh-TW.md) · [修改記錄](CHANGELOG.zh-TW.md)

## 開始使用

需要 **macOS 13 以上**，支援 Apple Silicon 與 Intel。

1. 解壓縮完整來源包，保留資料夾內的檔案結構。
2. 雙擊 `Build-on-Mac.command`。完成後，同一個資料夾會出現 `Rclone Browser Next.app`。
3. 開啟設定，選擇 **rclone 安裝位置**。資料夾中應有名為 `rclone` 的執行檔，也可直接選擇既有的執行檔。
4. 要新增雲端或 NAS 帳號，點左上角 **帳號設定（Config）**，依 rclone 的互動提示完成設定。
5. 在左右面板選擇位置，確認傳輸方向與操作，先做 **Dry Run** 查看結果，再開始傳輸。

建置使用 Mac 已有的 Apple 開發工具。一般建置不下載套件、不安裝 Homebrew、Node.js 或 rclone；編譯快取、暫存、記錄與產物都放在這個專案資料夾中。若尚未安裝 Apple Command Line Tools，腳本會說明缺少的工具並停止。

rclone 與 App 分開存放。沒有安裝 rclone 時，仍能開啟 App 設定位置；本機資料夾可直接瀏覽；遠端瀏覽與 rclone 傳輸等操作要等引擎可用。

## 這版的操作方式

### 選擇位置

左右面板各自選擇位置，來源與目標可以是本機、本機掛載的網路磁碟、雲端或 rclone remote。

位置選單提供常用 Mac 資料夾：個人資料夾、桌面、文件、下載項目、圖片、音樂、影片，以及目前掛載的磁碟。路徑由系統讀取，不固定使用者名稱。Cloud 與 NAS／伺服器按後端類型分組；WebDAV 等可能有多種用途的連線會保留明確的協定名稱。

檔案表格支援調整欄寬；縮窄欄位後，列底色仍延伸到面板邊緣。修改日期包含西元年。四個主題使用灰白或深灰底色，紫色、藍色用於選取、焦點與主要操作。預設為深紫主題。

### 複製、移動、同步與 Dry Run

| 操作 | 行為 |
|---|---|
| 複製 Copy | 將符合條件的來源檔案傳到目標，保留來源；不因來源缺少檔案而刪除目標 |
| 移動 Move | 成功傳送後移除對應的來源項目 |
| 同步 Sync | 讓目標符合來源及篩選條件；可能刪除目標中來源沒有的項目 |
| Dry Run | 用目前設定執行 rclone 預演，列出預計動作，不實際複製、移動或刪除檔案 |

Dry Run 仍會列目錄、讀取必要的比較資訊並產生日誌；若選擇需要內容雜湊的比較方式，也可能讀取檔案內容。預演後到正式執行前，來源或目標若變動，實際結果也會跟著改變。

移動、同步與刪除會先顯示原生確認視窗。按 Command＋Q 每次都會詢問；有工作時，會說明結束將停止傳輸、掛載或播放。已完成的檔案變更不會因退出而復原。

### 記住目前設定

點左上角 **記住**，會保存左右位置、傳輸方向、操作方式與全部傳輸選項。下次開啟 App 時還原這個工作環境，讓你接著操作；**不會自動執行傳輸**。

記住的環境不保留檔案勾選；要保留選取範圍，請儲存成 Task。

「預設啟動資料夾」適合指定固定起點；「記住」則同時保存當前兩側位置和傳輸設定。

### 儲存作業 Tasks

每個作業都有 **Dry Run、Run、Edit、Delete** 四個入口。儲存與編輯使用完整設定畫面，可以核對來源、目標、方向、複製／移動／同步、比較方式、略過條件、同步刪除時機、包含／排除規則、速度及其他傳輸參數。

編輯既有作業會更新同一個作業；另存新作業則建立副本。作業保留自己的傳輸選項，之後調整主畫面不會直接改寫它。執行時仍使用目前有效的 rclone、帳號設定檔與全域連線設定；作業內明確設定的逾時或額外參數可覆蓋對應預設。

## 設定

### rclone 安裝位置與更新

選擇資料夾就使用其中的 `rclone`。直接選擇執行檔時，同時以其父資料夾作為安裝位置，不需要再管理兩條互相競爭的路徑。

選完位置立即儲存、探測版本並刷新。更新會在目前指定的位置下載、驗證與替換；失敗時保留或還原舊版。引擎更新可在啟動時檢查，也可手動檢查，並支援稍後處理或跳過某個版本。

App 選單中有兩項更新：

- **檢查 rclone 更新**：檢查外部引擎，經確認後更新指定位置中的 rclone。
- **檢查 Rclone Next 更新**：檢查本專案的 GitHub 正式版本，提供新版下載頁與更新說明。這個入口不會直接覆寫正在執行的 App。

App 更新會檢查 [本專案的 GitHub Releases](https://github.com/jason840709/RcloneBrowserNext/releases)。若當時沒有可取得的正式版本，會顯示對應提示。外部 rclone 的更新功能可獨立使用。

### 外觀與語言

外觀變更立即套用，提供深紫、淺紫、深藍、淺藍。語言可選繁體中文、English、日本語或「預設（跟隨系統）」。跟隨系統時，以主要系統語言判斷：中文使用繁體中文，日文使用日本語，其他語言使用 English。

### 同時工作的數量

預設 **不限制同時工作的數量**，與原版直接啟動工作的方式一致。需要控制資源時，可以自行指定工作上限；這與單一工作內的「平行傳輸數」「平行檢查數」是不同層次。

0.3 的預設上限 2 會在升級時解除；先前另設的非預設數值會保留。0.4 之後明確選擇 2，會正常記住。已結束的工作保留最近 200 筆，執行中與排隊中的工作、另存的 Tasks 不受這個歷史筆數影響。

### 網路

代理可沿用啟動環境，或指定 HTTP／HTTPS／SOCKS 代理與例外位址。rclone 連線另可設定 IPv4／IPv6、來源 IP、連線逾時、傳輸閒置逾時、每秒請求數、瞬間請求上限、User-Agent 與停用 HTTP/2。

App 和引擎的更新下載支援系統代理、手動 HTTP CONNECT 與 SOCKS5。若手動代理位址本身是 `https://`，更新檢查會提示改用 `http://` 或 `socks5://`；這是目前原生更新連線的限制，rclone 傳輸仍可使用 `https://` 代理。

「來源 IP」是這台 Mac 可用的位址，不是 `en0` 之類的網卡名稱。每秒請求數用來降低 API 呼叫頻率，不等於傳輸速度限制；傳輸速度在傳輸選項中設定。HTTP/2 選項主要供代理或伺服器相容性排查使用。更新檢查使用 HTTPS 與代理設定，rclone 專用的 TPS、來源 IP 等選項不會套用到 App 自己的更新請求。

## SMB／NAS 比較

Finder 掛載的 SMB 路徑，對 rclone 屬於本機檔案系統。計算這些檔案的雜湊，會經由網路讀取內容。

**大小與修改時間（不計算本機雜湊）** 適合以 SMB 掛載的 NAS：使用 metadata 判斷，停用 local backend 的內容雜湊，避免單純為比較而讀回目標整個檔案。它能利用修改時間辨識同大小的修改，但在這個 local 傳輸情境不提供內容雜湊校驗；大小與時間都沒變的內容修改仍可能漏掉。這個選項只停用本機後端的雜湊，不會停用所有雲端後端的雜湊能力。

「只比大小」更快，但會略過同大小的內容修改；「大小＋雜湊」較重視內容比較，可能增加讀取量。各選項旁的 ⓘ 說明會指出行為、適用情況與代價。詳見 [NAS 比較說明](NAS_COMPARISON.zh-TW.md)。

## 為什麼體積小

這個 App 使用 Swift／AppKit，以及 macOS 內建的 WebKit，沒有在包內再放一份瀏覽器引擎或 Qt。rclone 也獨立安裝，因此 App 大小不包含 rclone。

來源 ZIP、解壓縮後的來源、編譯完成的 `.app`、外部 rclone 是四種不同大小，不能直接混在一起比較。建置腳本會列出你的 Mac 實際產生的 App 大小。功能完整性以功能對照、測試及實際使用結果判斷，檔案大小本身不代表功能是否完成。

## 簽章與驗證

在 Mac 建置完成後，腳本會對完整 App 建立本機簽章並驗證；可另執行 `Verify-App.command`。這不是 Apple Developer ID 簽章或公證，因此公開下載的 CI App 仍可能受到 Gatekeeper 限制。現階段建議使用來源包在自己的 Mac 建置。

測試方法與驗證範圍見 [驗證記錄](VALIDATION.zh-TW.md)。來源內附的測試使用合成資料；不包含真實雲端帳號、使用者的檔案列表或參考截圖。
