# Rclone Browser Next 使用手冊

作者：**Jason Chen**

Rclone Browser Next 是雙面板 rclone 圖形介面。左右兩側都能選取本機資料夾、雲端或 NAS／伺服器，並依指定方向複製、移動或同步檔案。

[專案首頁](../README.md) · [English](../README.en.md) · [Mac 建置說明](BUILD_MAC.zh-TW.md) · [功能對照](FEATURE_MATRIX.zh-TW.md) · [修改記錄](CHANGELOG.zh-TW.md)

Windows／Linux 請使用[相容版安裝包](BUILD_COMPATIBILITY.md)。以下原生操作以 Mac 版為主，傳輸設定與報告則三平台通用。

## 開始使用

Mac 版需 **macOS 13 以上**，支援 Apple Silicon 與 Intel。

1. 到[最新發布頁](https://github.com/jason840709/RcloneBrowserNext/releases/latest)下載適合這台 Mac 的版本：Apple 晶片選 `macOS_arm64.zip`，Intel 選 `macOS_x86_64.zip`。
2. 解壓縮後，將 `Rclone Browser Next.app` 放進「應用程式」並開啟。若系統擋下，請到「系統設定 → 隱私權與安全性」允許開啟。
3. 開啟「設定」選擇 **rclone 安裝位置**：可選取內含 `rclone` 的資料夾、直接挑選現有 `rclone` 執行檔，或由 App 下載安裝。
4. 點擊上方 **帳號設定** 新增連線：在預設的 **快速設定** 輸入帳號名稱、選擇服務，再按「登入並新增帳號」完成瀏覽器授權；NAS／伺服器則填入位址與帳密。旁邊的 **config** 可開啟傳統終端機設定。
5. 在左右面板選好位置、確認方向與操作方式，先按 **預演（Dry Run）** 檢查預計動作，再開始傳輸。

若要自行編譯，請下載完整原始碼包並執行 `Build-on-Mac.command`，詳見 [Mac 建置說明](BUILD_MAC.zh-TW.md)。

rclone 與 App 分開存放。尚未安裝 rclone 時仍可瀏覽本機資料夾，遠端瀏覽與傳輸則需先設定好 rclone。從舊版升級時，請先關閉 App，用新版 App 替換舊版；舊有的設定、已儲存作業與外部 rclone 都會直接沿用。

## 畫面與瀏覽操作

### 調整視窗大小

在 Mac 版拖曳視窗頂端空白處可移動視窗；雙擊空白處可將視窗放大至螢幕可用範圍，再雙擊一次還原。

### 選擇位置與分頁

左右面板各自管理位置與資料夾分頁，來源與目標都能任選本機資料夾、已掛載網路磁碟、雲端或 rclone 遠端連線。

位置選單提供 Mac 常用資料夾（個人資料夾、桌面、文件、下載項目、圖片、音樂、影片）、已掛載磁碟、雲端與 NAS／伺服器。每個分頁各自記錄瀏覽歷史，可用面板上的返回／前進按鈕、滑鼠側鍵（依游標所在面板切換）或 `Command + [`／`]` 切換。

### NAS 的兩種連線方式

位置選單的「NAS／伺服器」會在名稱右側標示連線方式：

- **Mac 掛載**：使用 Finder 已掛載的 NAS 共享資料夾。
- **SMB 直連**：由 App 直接連線至 NAS，不需先用 Finder 掛載。

若要新增直連，請打開「帳號設定」，選擇「SMB 直連（NAS／伺服器）」，填入 NAS 主機名稱或 IP、帳號與密碼。儲存後即可從位置選單挑選「SMB 直連」進入共享資料夾。

若透過 Mac 掛載時遇到特定日文或特殊符號檔名看得到卻打不開，可嘗試改用 SMB 直連；它能避開 Mac 掛載時的名稱轉換，但權限或 NAS 端的錯誤仍須另外處理。請先照上方步驟新增 SMB 連線，再打開來源面板的位置選單，選擇標有「SMB 直連」的 NAS，進入要同步的資料夾並建立新工作。直接重試舊工作仍會沿用原本的掛載路徑。

### 瀏覽快取、重新整理與取消載入

左右窗格會各自快取本次開啟期間讀過的雲端資料夾（本機資料夾每次都會重新讀取），返回或切回同一資料夾時可立即顯示。關閉 App 後快取即清除，也不會在背景定時重讀。

點擊某一側的 **重新整理** 會清除該窗格所有快取並重讀目前資料夾；若遠端檔案已被其他裝置修改，請按重新整理取得最新清單。在 App 內新增、改名、刪除檔案，或完成正式傳輸後，兩側受影響資料夾的快取都會自動更新。

載入新資料夾時，中央會顯示讀取轉圈與目標路徑；滑鼠移到轉圈上（或用鍵盤聚焦）會出現 **×**，點擊即可 **取消載入** 並退回上一個位置，不會影響另一側或進行中的傳輸。

## 傳輸與備份

### 複製、移動、同步與預演（Dry Run）

| 操作 | 行為 |
|---|---|
| 複製 Copy | 將來源檔案複製到目標，保留來源檔案，不會刪除目標多出的檔案 |
| 移動 Move | 檔案傳送成功，或目標已有依本次比對設定不需更新的副本後，刪除來源檔案 |
| 同步 Sync | 以來源為準單向更新目標，刪除同步範圍內目標多出的檔案 |
| 預演 Dry Run | 模擬執行並列出預計動作，不會實際複製、移動或刪除檔案 |

移動、同步與刪除前都會跳出確認視窗。同步採 rclone 單向 `sync`，並非雙向同步；選取範圍、排除規則與略過條件都會影響處理範圍，預設不會刪除目標中被排除的檔案。若開啟「刪除排除項目」，被排除的目標檔案也可能被刪除；讀取錯誤與刪除上限則可能讓部分刪除停止。工作失敗時，目標可能只完成部分更新。[rclone 同步說明](https://rclone.org/commands/rclone_sync/)

關閉 App（`Command + Q`）時，若無進行中或失敗／未完成的工作會直接退出；若有工作仍在執行、掛載或串流播放，確認退出後會先停止工作再關閉（已完成的檔案變更不會復原）。

### 常用備份方案

操作選單上方提供六種常用備份方案，選取後會自動套用適合的傳輸參數，不會改變左右位置或直接開始傳輸：

| 方案 | 同時傳輸／檢查數 | 主要設定 |
|---|---|---|
| 本機 → 本機 | 1／10 | 適合外接硬碟或另一顆磁碟；停用單檔分段並行 |
| 本機 → NAS | 1／10 | 減少對 NAS 同時寫入；停用單檔分段並行 |
| NAS → 雲端 | 7／10 | 多檔並行上傳 |
| 本機 → 雲端 | 7／10 | 多檔並行上傳 |
| 雲端 → 雲端 | 7／10 | 多檔並行傳輸（實際路徑視雲端服務商支援而定） |
| 雲端 → 本機／NAS | 1／10 | 減少對磁碟同時寫入；停用單檔分段並行 |

雜湊是依檔案內容算出的核對值。六種方案皆預設為**單向同步、比對大小與修改時間（不計算本機雜湊）、傳輸時刪除、不限刪除數**，並排除 `.DS_Store`、`._*`、`.Spotlight-V100`、`.Trashes`、`.fseventsd`、`.TemporaryItems` 等 Mac 系統檔（若需備份 `._*` 附屬檔可手動刪除此排除規則）。點擊方案旁的 × 可隱藏不常用的方案，日後可在傳輸選項中還原。「傳輸時刪除」表示檔案仍在傳送時就可能刪除目標多出的項目。若只想新增與更新、保留目標舊檔，請將操作改為「複製」。這些方案只排除列出的系統檔案，不會排除所有隱藏檔。已儲存的作業不會因切換方案而被改寫。

### 選取部分項目

只有來源側會顯示勾選框：未勾選時處理整個資料夾；有勾選時只處理勾選項目，並放到目標的同名路徑下。切換傳輸方向或交換左右面板時，會自動清除舊勾選。

- **複製／移動：** 可自由勾選檔案與資料夾。
- **同步：** 只能勾選一個或多個**資料夾**（例如勾選 `Photos` 與 `Documents`，就只同步這兩個子資料夾，目標裡的其他資料夾完全不會動到）。勾選部分資料夾同步時，不能開啟「刪除排除項目」，以免刪除選取範圍外的內容。同步不支援單選個別檔案；若要處理個別檔案請改用複製或移動。

### 外接磁碟的時間容許誤差

「時間容許誤差」留空時，Mac 版會依本機磁碟格式自動帶入適當誤差（FAT 為 2 秒、HFS+ 為 1 秒、exFAT 為 10 毫秒），避免因檔案系統時間精度不同而重複傳檔；若有手動填寫則以手動值為準。放大容差可能漏掉短時間內、大小不變的內容修改，請勿只為避免重傳而任意調高。[比較方式與限制](NAS_COMPARISON.zh-TW.md)

## 進度、報告與重試

### 速度與剩餘時間

傳輸速度只計算實際有檔案在傳的時間，不會被比對檔案或建立資料夾的時間拉低；遇到等待雲端確認檔案或比對階段時，速度旁會顯示小轉圈說明目前狀態。工作完成後會保留全程平均速度（早期設計依據見 [統計與 NAS 行為查核](RESEARCH_0.5.0.md)）。

### 統計數字與逐檔報告

工作卡片與「詳細資料與紀錄」會呈現檔案去向與處理明細：

| 欄位 | 說明 |
|---|---|
| 不用傳 | 依本次比對與略過設定，不需傳輸的紀錄數；未必核對過完整內容 |
| 已略過 | 依規則跳過的紀錄數，例如未選擇保留的符號連結（指向另一個檔案或資料夾的連結） |
| 已刪除 | 同步時在目標刪除的檔案數 |
| 錯誤 | 傳輸過程中發生的錯誤次數（同一檔案重試失敗會累計） |
| 檢查次數 | 位於詳細資料中，為 rclone 檢查過的項目數（含資料夾） |

展開「詳細資料與紀錄」可按**全部、比對、略過、已完成、錯誤**分頁查看每筆檔案的時間、動作與訊息，並可匯出完整 JSONL 逐檔報告或原始比對紀錄。成功完成的工作會在下次啟動 App 時自動清除，若需長期留存報告請先匯出。

### 出錯重試與活動檔案

可在「設定 → 一般 → 出錯時重試」選擇重試方式，搭配傳輸選項中的「整個傳輸重試」設定最多執行幾輪（含第一輪）：

- **只重試出錯的檔案（預設）**：遇到網路逾時、雲端限流等暫時性錯誤，下一輪只處理失敗的檔案；找不到檔案、權限不足、空間已滿等無法靠重試解決的錯誤則不再重試。若遇資料夾暫時無法讀取、錯誤無法對應個別檔案、開啟「刪除排除項目」或出錯檔案超過 5 萬個，仍會重新檢查全部檔案。
- **整個重新檢查**：維持 rclone 預設行為，出錯時重新掃描比對整個資料夾。

同步若因錯誤暫停刪除，錯誤解決後會在剩餘嘗試次數內重新檢查並補做刪除。預演不重試；每輪安排會寫入工作紀錄與逐檔報告。

若備份期間來源檔案持續變動（如執行中的資料庫或大型日誌），rclone 可能會因大小驗證失敗而重傳。備份這類資料夾前建議先關閉寫入程式，或使用系統／資料庫快照；詳見[活動檔案的備份說明](RESEARCH_0.7.0.md)。

「符號連結」可選擇略過或保留：保留時在雲端會存成 `.rclonelink`，下載時同樣勾選保留即可還原。

### 傳輸佇列與停止工作

傳輸成功的工作會標示為「已完成」，並在下次開啟 App 時自動清除；失敗、取消或中斷的工作則會保留在清單中供檢查與重試。

點擊垃圾桶清除工作時，若清單中仍有進行中或排隊中的工作，可選擇「終止進行中並清除」或「只清除已完成」。點擊停止傳輸時，App 會先請 rclone 正常收尾，等程序結束後再更新狀態（已完成的複製、移動或刪除不會復原；詳見 [停止與清理行為](RESEARCH_0.6.0.md)）。

## 儲存工作區與作業（Tasks）

工具列的儲存選單提供兩種保存方式：

- **儲存工作區**：記住目前的左右位置、方向、操作方式與傳輸選項，下次啟動時自動還原（不保存勾選的檔案，也不會自動開始傳輸）。
- **儲存為作業（Task）**：將目前設定與勾選範圍命名存成作業，之後可在「作業」頁隨時執行（Run）、預演（Dry Run）、編輯（Edit）或刪除（Delete）。

## 設定與網路

### rclone 安裝位置與更新

在設定中選取 `rclone` 所在資料夾或執行檔即可立即套用。公開專案位於 [jason840709/RcloneBrowserNext](https://github.com/jason840709/RcloneBrowserNext)，App 選單提供兩個獨立的更新檢查：

- **檢查 rclone 更新**：下載並替換指定位置中的外部 rclone（失敗時會自動還原舊版）。
- **檢查 Rclone Next 更新**：查詢 [GitHub Releases](https://github.com/jason840709/RcloneBrowserNext/releases) 是否有新版 App 並提供下載頁連結。

### 外觀、縮放與背景提醒

- **外觀**：提供自動（跟隨系統）、淺色、深色模式，搭配紫、綠、藍三種強調色；執行中的 Dock 與選單列圖示也會跟著變色。
- **介面大小**：提供 **80%、90%、100%、110%、125%** 五段縮放，預設 100% 與 macOS Finder 清單文字大小一致。
- **語言**：支援繁體中文、English、日本語與跟隨系統。
- **背景提醒**：Mac 版在「設定 → 介面 → 背景執行」開啟「在背景完成或失敗時，讓 Dock 圖示跳動提示」後，背景工作完成或失敗時 Dock 圖示會跳動提醒，直到切回 App。

### 同時工作數與網路

預設**不限制同時執行的工作數**，可在設定中自行指定上限（此設定控制同時跑幾個工作，單一工作內的平行傳檔數則在「傳輸選項」設定）。

網路設定支援系統代理或手動指定 HTTP／HTTPS／SOCKS5 代理，以及 IPv4／IPv6、來源 IP、逾時、每秒請求數（TPS）、User-Agent 與停用 HTTP/2。（注意：App 自身的更新檢查目前不支援 `https://` 代理位址，請改填 `http://` 或 `socks5://`。）

## SMB／NAS 比對建議

Finder 掛載的 SMB 共享資料夾對 rclone 而言屬於本機磁碟，若計算檔案雜湊會透過網路把整份檔案讀回 Mac。

因此 NAS 方案預設採用 **大小與修改時間（不計算本機雜湊）**，只靠檔案大小與修改時間判斷是否需要更新，省去為了比對而讀回整份檔案的流量。若要比對內容，可選「大小＋雜湊」，但兩端須有共同支援的雜湊；沒有時會退回只比大小。SMB 直連本身不提供雜湊，不能靠這個選項完成內容核對；各選項的詳細比較請見 [NAS 比較說明](NAS_COMPARISON.zh-TW.md) 與 [rclone 跨服務傳輸說明](https://rclone.org/faq/#can-rclone-sync-directly-from-drive-to-s3)。

若要確認雲端服務能否比對雜湊，請查看 [rclone 服務功能表](https://rclone.org/overview/#features)的 Hash 欄：兩端至少要有一種相同的名稱（例如 md5），且檔案本身須提供該值；「-」表示不支援。App 目前不會在每筆「不用傳」旁另外標示是否退回只比大小，因此不能只憑工作成功就判定完整內容已核對。SMB 直連不支援雜湊；若改用 Mac 掛載路徑比對完整內容，會增加讀取檔案的時間與流量。

## 帳號設定

點擊工具列「帳號設定」即可開啟圖形化設定視窗（旁邊的 `config` 可開啟傳統終端機設定）：

1. **快速設定（預設）**：輸入自訂名稱、選擇服務（Google Drive、OneDrive、Dropbox 排在最前），點擊 **登入並新增帳號** 在瀏覽器完成授權即可。部分服務可使用共用登入。Google Drive 的共用登入 ID 將於 2026 年停用，請展開自訂憑證，填入自己申請的 Client ID 與 Client Secret（Google Cloud 登入應用程式的憑證，不是 Gmail 帳號密碼）（[rclone 官方教學](https://rclone.org/drive/#making-your-own-client-id)）。
2. **詳細設定**：將該服務的所有設定與進階選項集中在同一頁表單，適合需要唯讀權限、自訂端點或特殊參數時使用。

## 簽章、架構與授權

Mac 版建置後會建立本機 ad-hoc 簽章（可用 `Verify-App.command` 檢查），因沒有 Apple Developer ID 簽章，也未經 Apple 公證，下載預編譯版首次開啟可能需在「系統設定 → 隱私權與安全性」手動允許，或直接用原始碼包在本機執行 `Build-on-Mac.command` 建置。測試與驗證紀錄請見 [驗證記錄](VALIDATION.zh-TW.md)。

本專案由 **Jason Chen** 開發，採 MIT 授權，參考 [Rclone Browser](https://github.com/kapitainsky/RcloneBrowser) 的功能分類與 ForkLift 的雙面板版面，以 Swift／AppKit 與 React 全新實作（見 [功能對照](FEATURE_MATRIX.zh-TW.md)）。

## 清除工作紀錄與匯出報告的注意事項

報告中的比對結果和執行結果分開記錄。「目標缺少檔案」表示需要處理，尚未表示傳送成功；同一路徑也可能先失敗、重試後成功，因此錯誤次數與報告筆數都不等於最後未完成的檔案數。傳輸途中匯出的是當時的報告快照。舊工作若沒有逐檔資料，無法事後補出。

垃圾桶依目前分頁處理：「已結束」會清除該頁的成功、失敗、取消及中斷紀錄；「只清除已完成」只移除成功紀錄。清除前請先匯出需要留存的報告。

## 修復舊版留下的本機暫存檔

Mac 選單的「修復未完成的本機複製…」可匯入該次工作的 JSONL 報告，核對因改名失敗留下的 `.partial` 暫存檔。先停止相關傳輸，再依畫面核對來源與暫存檔的完整內容。支援不覆寫的安全改名時會恢復正式檔名；否則另建並驗證新檔，保留原暫存檔。重建需要額外空間；未完成的新檔不算修復成功。

「清理已核對暫存檔」只處理有完整修復收據的重建結果，會再次確認檔案身分與內容；有變動就保留，不會刪除來源或正式檔案。
