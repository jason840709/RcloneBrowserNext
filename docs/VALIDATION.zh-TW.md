# 0.9.3 驗證方式與結果位置

0.9.3 延續 Mac、Windows 與 Linux 的統一發布流程，將帳號設定改為快速登入與同頁詳細表單。保留 0.9.2 的 Mac 持續 Dock 提醒、Windows 已驗證的 r1 檔案系統實作，以及三平台的讀取動畫。

正式發布必須通過同一個來源 commit 的完整 CI：Web 介面與 WebKit 新增案例、Mac arm64／Intel 核心與原生測試、macOS 26 原生測試、Linux 套件與原生視窗，以及 Windows 建置、乾淨安裝、檔案操作、真實 WebView2 互動和三種舊版升級（0.9.0、0.9.0-r1、0.9.2）。0.9.2 升級案例另外保留已設定為關閉的 Dock 提醒偏好，不讓新增預設覆寫既有值。

[執行紀錄](https://github.com/jason840709/RcloneBrowserNext/actions/workflows/macos.yml) 的每項工作保留結果。Windows 的 `candidate-verification.json` 逐項核對測試名稱、數量及執行檔雜湊；未完成或失敗的案例不能透過發布門檻。Web 的 JSON 報告區分 Chromium 全套回歸與 WebKit 的動畫、設定和帳號案例。應核對 `v0.9.3` 標籤所指向的來源 commit；未發布的開發執行結果不可當作正式版已通過。發布後的精確來源、工作編號與檔案校驗值另收錄在私人交接包。

## 新功能的測試範圍

Dock 測試確認背景完成／失敗使用持續提醒、重複事件去重、多工作共用尚未確認的提醒、切回後取消與再次提醒，以及前景、取消、預演、關閉開關、退出和原生 API 呼叫。自動化驗證的是事件判斷及 AppKit API，不宣稱已量測每台使用者電腦上的 Dock 動畫像素。系統的 Dock 動畫偏好仍然生效。

帳號核心測試使用真實 rclone 與隔離設定檔，涵蓋服務清單、選定路徑、暫存、儲存、取消、外部修改衝突、刪除、密碼保留、Unicode 名稱及舊 API 相容性。0.9.3 增加同頁批次欄位、快速新增自動儲存、必填與未知問題停止、重複步驟保護、加密設定檔解鎖，以及三個常用雲端服務真正到達 OAuth 本機登入入口的測試。新密碼另透過真實 WebDAV 驗證，避免只檢查「文字看起來有編碼」卻不能登入。

Windows 的設定檔路徑先正規化再比較，並讀回內容核對，不要求兩個程式使用相同的斜線字元。介面測試檢查快速／詳細表單、常用服務排序、雙憑證區、必要伺服器欄位、真正鎖定時才解鎖、自動開啟登入、完成儲存、返回修改、等待取消結束後重試，以及長選項在窄視窗與放大畫面下的布局。這些測試沒有代替帳號擁有者完成 Google、Microsoft 或 Dropbox 的真實雲端登入，也沒有驗證每個租戶的授權政策。

進度測試確認六種主題、左右往返、軌道邊界、減少動態效果，以及排隊、掃描、已知總量、停止與完成的切換。Windows／Linux 的安裝後原生視窗另檢查同一份 CSS 動畫能實際播放。

Windows UI 測試以本機 alias 遠端搭配真正 rclone 執行，不含回報者的私人雲端帳號。Windows Server 2025 x64 與 Ubuntu 24.04 CI 不涵蓋所有桌面版本、裝置或雲端供應商。Mac 公開 App 為 ad-hoc 簽章，Windows 安裝程式未具 Authenticode 簽章。
