# 0.9.5 驗證範圍與結果位置

0.9.5 修正遠端清單含有同名項目時的畫面列識別衝突，新增來回導航及重新整理的實際畫面回歸。保留 0.9.4 的資料夾工作階段快取、每窗格全深度重新整理與可取消載入。三平台維持統一發布，快速／詳細帳號設定、Mac 持續 Dock 提醒與 Windows R1 檔案系統實作延續。

本文件列出本版的測試範圍與發布條件。**同一來源 commit 的正式 CI 尚未完成前，不將測試要求寫成已通過結果，也不填入未取得的通過數量。** 本機或較早版本的結果不能代替正式版證據。

## 發布門檻與查核方式

正式發布須通過 Web 介面、Mac arm64／Intel 核心及原生測試、macOS 26 原生介面、Linux 套件與原生視窗，以及 Windows 建置和安裝後驗證。Windows 保留乾淨安裝、檔案操作、真實 WebView2 互動，升級 baseline 為 0.9.0、0.9.0-r1、0.9.2、0.9.3、0.9.4；0.9.2 以後的 baseline 須保留已設定的 Dock 提醒偏好與原有設定。

[CI 執行紀錄](https://github.com/jason840709/RcloneBrowserNext/actions/workflows/macos.yml) 保留各工作的日誌及結果。應核對 `v0.9.5` 標籤、來源 commit、CI run、候選安裝檔與正式資產的校驗值一致。Windows 的 `candidate-verification.json` 核對測試名稱、數量與執行檔雜湊；缺漏或失敗不能視為通過。Web JSON 報告區分 Chromium 全套回歸與 WebKit 明列的動畫、設定、帳號及導航案例。單一工作成功不能代替完整發布門檻。

## 0.9.5 新增驗證範圍

使用含同名、同路徑項目的合成清單重現「第一層 → 子資料夾 → 返回 → 另一子資料夾 → 返回」；核對每次畫面上的完整名稱序列、實際列數及底部計數。重新整理須重新呼叫原生清單介面，回應正確時畫面也須正確，所有同名項目都保留。測試應涵蓋快取命中與強制讀取，不可只檢查底層陣列長度。`duplicate-entry-navigation.spec.ts` 同時列入 Chromium 全套與 WebKit 指定回歸。

## 延續 0.9.4 的驗證範圍

| 範圍 | 必須核對的行為 |
| --- | --- |
| 工作階段快取 | 回訪命中時不再啟動 listing；左右窗格各自管理；64 個資料夾、50,000 個項目與估計 16 MiB 上限採最近最少使用淘汰；沒有定時網路刷新。 |
| 全深度重新整理 | 清掉該窗格所有層級、分頁與帳號的快取，立即重新取得目前位置；回訪其他已清掉位置時重新讀取；另一窗格與瀏覽歷史保留。 |
| 變更後失效 | 新增、重新命名、刪除與正式傳輸結束後處理兩側相關位置；失敗／取消的部分傳輸同樣處理；移動含來源，Dry Run 不處理；帳號或連線變更清除兩側。 |
| 導航與競態 | 成功才更新路徑、清單及歷史；取消／失敗不把目標路徑當成成功位置；晚到回應不能覆蓋目前結果或重新放回已失效的快取。原位置在另一個目錄載入期間被傳輸修改時，取消／失敗會補讀原位置並保留歷史。 |
| 原生清單取消 | 使用隔離設定與可控制的本機慢回覆，讓真正 rclone 進入 listing 後取消，核對對應子程序退出；取消其中一個 request 時，其他 listing 不受影響，後續 listing 可成功，傳輸仍可繼續。Mac、Windows、Linux 都須執行此範圍。 |
| 共用介面 | Chromium 與 WebKit 核對中央圓環、hover／鍵盤 focus 取消、舊清單操作鎖定、六種主題、縮放及 reduced motion。畫面移除 loading 本身不能代替原生程序退出證據。 |
| 捲軸保留區 | 長、短、空清單及搜尋零結果都保留相同垂直捲軸寬度及不透明軌道；不需捲動時只隱藏滑塊，交錯列底色不進入保留區，表頭與內容邊界保持對齊。 |

## 延續的回歸範圍

帳號核心使用真實 rclone 與隔離設定檔，涵蓋服務清單、選定路徑、暫存、儲存、取消、外部修改衝突、刪除、密碼保留、Unicode 名稱、快速新增、同頁詳細欄位、加密設定解鎖及未知問題停止。OAuth 測試到達本機登入入口；新密碼以本機 WebDAV 登入檢查。介面保留自訂 Client ID／Secret 同區、返回修改、重試、取消清理及窄視窗布局。

傳輸回歸仍須檢查正常複製／移動／同步、預演、報告、錯誤與重試、停止後 partial 清理，以及其他工作不受影響。既有的傳輸取消案例與本版的 listing 取消是不同範圍，兩者都要保留。

Dock 測試涵蓋背景完成／失敗持續提醒、去重、切回後取消與再次提醒，以及前景、取消、預演、關閉開關和退出。進度回歸涵蓋排隊、掃描、未知／已知總量、停止、完成、六種主題及減少動態效果。Windows／Linux 原生視窗檢查共用介面與 bridge；Windows 的檔案路徑先正規化再比較並讀回內容。

## 驗證限制

本機 listing fixture 可檢查取消、隔離與狀態處理，不能保證每個雲端供應商的第一次載入時間，也不代表已量測真實帳號的速度。帳號測試不替使用者完成 Google、Microsoft 或 Dropbox 的雲端登入；服務與租戶的授權政策仍由供應商決定。

原生 Dock 測試確認事件判斷及 AppKit API，沒有量測每台電腦的實體 Dock 動畫。Windows Server 2025 x64、Ubuntu 24.04 與 CI 的 macOS 版本也不涵蓋所有桌面系統及裝置。Mac 公開 App 使用 ad-hoc 簽章，Windows 安裝程式沒有 Authenticode 簽章。
