# Rclone Browser Next 0.9.0 驗證記錄

本版正在驗證正式 Web 成品及原生安裝包；完成結果將記錄受測來源、各平台結果與發布檔校驗值。

## 本版範圍

- 正式 Web 介面的工作區／作業工具列、保存行為、外觀排列、三語說明與限速摘要。
- Mac 真正 WKWebView 與原生載入層的圖示及文字位置、尺寸、字級、顏色與介面比例；保留無白閃、側鍵、退出政策及簽章測試。
- macOS 15 Apple Silicon／Intel 與 macOS 26 原生介面；Windows／Linux 的共用核心、封裝及原生視窗啟動。

既有傳輸、選取範圍、作業與工作區資料格式未改。Finder 與退出後 Dock 的持續換色未實作，現有固定圖示保持不變；測試不將實體滑鼠或使用者電腦的 Dock 呈現算成自動化驗證。
