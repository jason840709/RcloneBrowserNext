# Rclone Browser Next 0.10.2

這一版重新整理傳輸進行中的速度算法、統計欄位與錯誤提示，讓畫面上的數字與燈號一目了然。

## 傳輸速度只計算實際傳檔時間

0.10.1 在計算速度與平均速度時，把 rclone 比對檔案與建立資料夾的時間也算了進去，導致比對時間一長就把速度拉低。

- 現在速度只計算 rclone 實際有檔案在傳的時間（`transferTime`），工作完成後的平均速度也不再被比對階段拉低。
- 當 rclone 只在比對檔案或建立資料夾時，速度欄會顯示「檢查中」，剩餘時間則保留上一次的估計值。

註：傳檔到本機外接硬碟時，開頭幾秒速度可能特別高，這是因為 macOS 會先把資料寫入記憶體快取，幾秒後就會回到硬碟的實際寫入速度。

## 傳輸卡片統計改依「檔案去向」分類

原本第二排的「需傳輸檔案」「已傳輸」與第一排重複，而「已檢查」又常被誤以為是不用傳的檔案數（其實包含資料夾檢查）。現在調整為：

- **第一排**：已傳資料量、已傳檔案、速度、剩餘時間。
- **第二排（檔案去向）**：不用傳（依設定不需傳輸）、已略過（依規則跳過）、已刪除（僅同步時顯示）、錯誤次數。
- 「檢查次數」移至「詳細資料與紀錄」內，並補上清楚的滑鼠提示說明。

## 錯誤改用小燈號與白話說明

過去只要 rclone 回報任何錯誤（例如 Google Drive 共用憑證觸發「每分鐘請求次數上限」，rclone 其實會自動放慢並重試），畫面就會跳出大片紅框與英文原始訊息。現在改為：

- **一行白話摘要**：以一顆小燈號搭配白話標題（例如「雲端暫時限流，會自動重試」），處理建議與原始錯誤則收在「說明」裡。
- **橘燈（注意）**：rclone 會自動重試的狀況（如限流、網路瞬斷、雲端暫時錯誤），進行中會緩慢閃爍。
- **紅燈（需要處理／緊急）**：需手動處理的問題（如權限不足、檔名過長）；只有整個工作無法繼續時（如雲端或磁碟空間已滿、登入過期）才會自動展開說明。
- **重試成功後自動收起**：若工作最終成功完成，代表中途的暫時性錯誤已在重試後解決，畫面不再顯示燈號與紅字。

提示：使用 Google Drive 內建共用憑證時較容易遇到限流，且 rclone 已預告共用 ID 將於 2026 年內停用，建議依 [rclone 官方說明](https://rclone.org/drive/#making-your-own-client-id) 申請並填入自己的 `client_id`。
