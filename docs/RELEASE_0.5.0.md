# Rclone Browser Next 0.5.0

這版調整了雙面板的瀏覽方式、NAS 備份選項，以及傳輸時的速度與剩餘時間顯示。

## 這次更新

- 錯誤訊息改成完整卡片；空作業頁只顯示新增提示，沒有不能操作的假資料列。
- 儲存提示改為浮動通知，不推擠畫面，約五秒後自動收起。
- 選中的資料夾分頁與內容連成一體，路徑與導覽按鈕合併；每個分頁保留自己的返回／前進紀錄，支援滑鼠側鍵。
- 操作選單加入本機→NAS、NAS→雲端、本機→雲端三個方案；可以隱藏與還原。
- 新預設採大小與修改時間、不計算本機雜湊、傳輸時刪除、不限刪除數。已儲存作業保留原設定。
- 同步明確以來源為準，只更新目標。比對方式、排除、重試等選項補上短說明與詳細提示。
- 以最近最多60秒的既有容量統計估算速度及剩餘時間；完成後保留全程平均。百分比顯示一位小數。
- 大目錄只繪製可見資料列，進度更新不重新掃描完整檔案清單。

本機→NAS 方案使用同時傳輸1個檔案、同時檢查10個檔案，並停用單檔多路並行。三個方案都排除指定的 Mac 暫存項目；`._*` 可能包含 Mac 延伸資料，需要保留時可移除該條規則。

不計算本機雜湊可以減少為了比對而讀回整份 NAS 檔案的流量，但不提供本機端的內容雜湊校驗。NAS→雲端的實際變更內容仍通常經過執行 rclone 的 Mac。

## 下載與安裝

需要 macOS 13以上。rclone 另行安裝，在 App 設定指定位置。

- **Mac_Local_Build.zip**：完整來源與已建好的介面資源。解壓縮後雙擊 `Build-on-Mac.command`，使用 Mac 已有的 Apple Command Line Tools 或 Xcode。一般建置不下載套件，快取與產物留在同一專案資料夾。
- **macOS_arm64.zip**：Apple Silicon版本。
- **macOS_x86_64.zip**：Intel版本。

原生App由 GitHub的Mac建置流程產生，完整資源裝入後才建立ad-hoc簽章並驗證。**沒有Apple Developer ID簽章或公證**；下載的App仍可能受到Gatekeeper限制。如需在自己的Mac建立本機簽章，請使用來源建置包。

升級前先結束舊版；新版本沿用既有設定與儲存作業，不需要重新下載外部rclone。

## 驗證

本次Linux環境六套Swift測試共101項通過，介面86個不同案例通過；四主題80組指定配色對比檢查通過。Mac原生下載檔只有在Apple Silicon和Intel建置、簽章驗證與測試工作都成功後才會發布，執行記錄可在[Actions](https://github.com/jason840709/RcloneBrowserNext/actions)查看。

CI不等於在使用者的Mac上操作過介面：實體滑鼠側鍵、真實NAS／雲端傳輸速度，以及下載後Gatekeeper體驗，仍需實際環境確認。完整測試範圍與比較方式取捨見來源中的驗證及NAS文件。
