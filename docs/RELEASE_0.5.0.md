# Rclone Browser Next 0.5.0

這一版改進了雙面板瀏覽體驗、NAS 備份方案，以及傳輸時的速度與剩餘時間估算。

## 更新重點

- 目錄錯誤改用完整提示卡片；儲存成功等通知改為浮動自動收起，不推擠畫面。
- 資料夾分頁與下方清單連為一體，合併位置與路徑導覽列；各分頁獨立保留返回／前進歷史並支援滑鼠側鍵。
- 操作選單新增「本機 → NAS」、「NAS → 雲端」、「本機 → 雲端」三種備份方案（可隱藏與還原）。
- 新方案預設採用「大小與修改時間（不計算本機雜湊）、傳輸時刪除、不限刪除數」，已儲存的舊作業則保留原設定。
- 以最近 60 秒內的處理容量變化估算速度與剩餘時間，工作完成後保留全程平均速度，百分比顯示至小數點後一位。
- 大型資料夾採用虛擬捲動（只渲染可見列），進度更新不再重掃整份清單。

「本機 → NAS」方案預設同時傳輸 1 個檔案、檢查 10 個檔案，並停用單檔分段並行，同時排除 `.DS_Store`、`._*` 等 Mac 暫存檔（若需備份 `._*` 附屬檔可手動刪除該規則）。不計算本機雜湊可省去為了比對而讀回整份 NAS 檔案的網路流量。

## 下載與安裝

需 macOS 13 以上，外部 rclone 請在 App「設定」中指定位置：

- **Mac_Local_Build.zip**：完整原始碼與建置腳本，解壓縮後雙擊 `Build-on-Mac.command` 即可在本機編譯。
- **macOS_arm64.zip**：Apple Silicon 版本。
- **macOS_x86_64.zip**：Intel 版本。

預編譯 App 採用本機 ad-hoc 簽章（沒有 Apple Developer ID 簽章，也未經 Apple 公證），首次開啟若遭 Gatekeeper 阻擋，請至「系統設定 → 隱私權與安全性」允許開啟，或改用原始碼包在本機建置。升級時直接覆蓋即可，原有設定與作業都會保留。
