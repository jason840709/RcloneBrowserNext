# Rclone Browser Next 0.6.0

這次整理了工作記錄與停止流程，補上逐檔傳輸報告、六種備份方案及部分資料夾同步，並加入綠色主題和介面大小設定。

## 工作記錄與停止傳輸

- 在「已結束」分頁可清除完成、失敗、取消或中斷的記錄，不會停止其他正在執行的工作。
- 在「全部」或「進行中」有活動工作時，清除按鈕會提供三種選擇：終止進行中並清除、只清除已完成、取消。只清除已完成不會刪除失敗或取消的記錄；沒有符合的工作時會停用該選項。
- 確認清除時固定當下選定的工作編號，之後新增的工作不受影響。尚未真正停止的工作會保留，不會直接從畫面消失。
- 按下停止後顯示「正在停止」。先送出 SIGINT，等待 10 秒仍未結束才升級為 SIGTERM，再過 2 秒仍未結束才送 SIGKILL。這些秒數是 App 的等待政策，不代表每一種目的端都能在期限內清理完畢。
- 工作頁會顯示一般停止或強制停止的提示，並保留實際程序結束狀態。重複按下停止不會重建一組清理計時器。
- 重開 App 時清除上次成功完成的記錄，保留失敗、取消及中斷的工作供檢查或手動重試。儲存作業（Tasks）另外保存，不會跟著清除。
- 自動整理歷史時保留最近 200 筆完成、失敗或使用者取消的工作；進行中、等待中及中斷的工作不計入這個數量。中斷的工作會保留到使用者手動清除，也不會因為累積太多歷史記錄而禁止新增傳輸。

**停止不會復原已完成的複製、移動或同步刪除。** 未完成檔案與雲端上傳區塊由 rclone 依後端能力嘗試處理，不能保證全部清除。App 清除的是自己的工作記錄，不會猜測暫存檔名或自行刪除傳輸目的檔案。Mac 系統複製與部分雲端流程有不同限制，詳見 [停止傳輸研究](https://github.com/jason840709/RcloneBrowserNext/blob/v0.6.0/docs/RESEARCH_0.6.0.md)。

## 逐檔傳輸詳情

- 分開顯示 rclone 的已傳輸、已檢查、需傳輸及錯誤統計；Checks 也可能包含需要傳輸的檔案或刪除檢查，不能直接當成略過檔案數。
- 提供逐檔比對、略過、成功動作與錯誤列表。比對結果中的「目的地缺少」或「不同」只是候選動作，真正完成以 rclone 的成功紀錄為準。
- 略過列表表示依目前比對或略過規則不需複製；同一個檔案重試時可能再次出現。列表及計數保留這些紀錄，不把事件次數當成不重複的最終檔案數。
- 錯誤列表保留可取得的檔名與原因；重試後恢復的錯誤仍可查閱。無法對應到檔案的連線或工作錯誤會另外標示，不猜測檔名。
- 透過既有 JSON 記錄和標準輸出的比對紀錄收集資訊，不為了畫面重新掃描來源、目的地或計算內容雜湊。列表採小批分頁，匯出提供 JSONL 與原始比對記錄；執行中的匯出採固定快照，不會混入後續追加的半筆資料。

## 備份方案、比對與選取範圍

- 提供本機 → 本機、本機 → NAS、NAS → 雲端、本機 → 雲端、雲端 → 雲端、雲端 → 本機／NAS 六種方案。
- 雲端上傳與雲端互傳使用 7 個平行傳輸、10 個平行檢查；寫入本機或 NAS 使用 1 個傳輸、10 個檢查，並停用單檔分段並行。降低並行 I/O 不等於保證消除硬碟碎片。
- 在來源只勾選資料夾時，可同步目標下的同名子資料夾，選取範圍以外的目的項目會保留。選取範圍同步不允許「刪除排除項目」；搭配包含規則時，同時考慮兩端符合規則的名稱，讓選取範圍內多出的目的檔案仍能被同步刪除。
- Mac 會讀取實際掛載磁碟的檔案系統類型。修改時間容差留白時，針對已知的 FAT、HFS+、exFAT 時間精度套用相應容差，減少時間捨入造成的重傳；手動設定優先。這不代表已判定使用者的外接硬碟格式，也不會自動停用 APFS 系統複製或改成只比大小。
- 時間容差仍有取捨：同大小檔案在容差內修改可能不被辨識。正在使用的資料庫也需要相應的備份方式，不能只靠同步參數保證一致性。

## 配色、圖示與介面大小

- 加入黑綠、淺綠，與原有黑紫、淺紫、黑藍、淺藍合為六種主題。背景仍以中性灰階為主，紫、藍、綠用在按鈕、選取狀態與重點資訊。
- 保留 Jason 提供的圖示造型與眼睛修正，提供對應主題的紫、藍、綠版本。執行中的 App／Dock 及介面圖示會跟隨色系；Finder 裡的安裝圖示保留預設紫色，不改寫已簽章的 App 資源。
- 介面大小提供 **80%、90%、100%、110%、125%**，100% 為原來的大小。文字、圖示與控制項一起調整，變更立即套用並保留到下次啟動。
- 縮放使用 Mac 內建 WebKit 的頁面比例；檔案拖放與滑鼠側鍵的座標也依比例換算，避免放大或縮小後指向錯誤面板。
- 調整檔案清單與詳情區域的捲軸，增加可操作的寬度，並維持欄位與內容的對齊。

## 下載與安裝

需要 **macOS 13 以上**，支援 Apple Silicon 與 Intel。rclone 保持外部安裝，升級 App 不需要重新下載引擎。

本機建置包解壓縮後，雙擊 `Build-on-Mac.command`，使用 Mac 已有的 Xcode 或 Apple Command Line Tools 建立 App。一般建置不會自行安裝 Homebrew、Node.js 或開發工具；快取與產物留在專案資料夾。

下載的原生 App 採 **ad-hoc 簽章，沒有 Apple Developer ID 簽章或公證**，仍可能受到 Gatekeeper 限制。詳見 [Mac 建置說明](https://github.com/jason840709/RcloneBrowserNext/blob/v0.6.0/docs/BUILD_MAC.zh-TW.md)。
