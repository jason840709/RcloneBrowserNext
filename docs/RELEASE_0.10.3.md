# Rclone Browser Next 0.10.3

這一版修正 0.10.2 的三個顯示細節：速度欄常被狀態文字蓋掉、滑鼠提示感應範圍太小，以及在 macOS 26 以上自行編譯時工具列出現圓框的問題。

## 速度欄不再被文字蓋掉

0.10.2 只要超過 5 秒沒有新進度，就會把速度欄整格換成「等待檔案完成」或「檢查中」。但在上傳大量小檔到 Google Drive 等雲端時，每個檔案傳完都要等雲端確認，導致速度欄大半時間都被文字蓋住。

- **持續顯示速度數字**：等待雲端確認檔案時，速度與剩餘時間改看最近約一分鐘的平均，不會突然掉到 0；比對檔案或建立資料夾時，則維持上一次的傳輸速度。
- **以小轉圈代表等待狀態**：上述兩種情況會在速度數字旁顯示一個小轉圈，滑鼠移過去即可查看目前在等什麼。
- 以真實的 Google Drive 1432 秒上傳紀錄實測：0.10.2 有 58% 的時間速度被文字蓋住，0.10.3 則全程保留速度顯示（僅在超過一分鐘完全無資料傳輸的 7% 時段顯示 0）。

## 擴大滑鼠提示感應範圍

- 傳輸卡片與「詳細資料與紀錄」中的每個統計項目，從名稱、數字到下一個項目之前的空白處都能觸發滑鼠提示，不必對準標題文字。
- 傳輸選項視窗中的滑鼠提示同樣涵蓋整列（包含左側名稱與右側輸入欄）。

## 固定 Mac 工具列按鈕外觀

使用 macOS 26 以上的新版 Xcode／Command Line Tools 從原始碼編譯時，系統預設會在每個工具列按鈕外加上玻璃圓圈。現在建置腳本已固定指定以 macOS 15 外觀顯示，確保無論用哪一版開發工具編譯，工具列都維持原本乾淨無外框的設計。
