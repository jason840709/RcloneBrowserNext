# Rclone Browser Next 0.10.3

這一版修正 0.10.2 傳輸畫面的幾個顯示問題：速度欄常被一段文字整格蓋掉、滑鼠提示很難觸發，以及從原始碼自行建置的 Mac 版工具列外觀。傳輸、比對與帳號設定的行為沒有改變。

## 速度欄不再被文字蓋掉

0.10.2 在 rclone 有檔案超過 5 秒沒有新進度時，把速度整格換成「等待檔案完成」；只在比對檔案時換成「檢查中」。上傳很多小檔案到 Google Drive 這類雲端時，每個檔案送出後要等雲端確認收到才算完成，常常要等十幾秒到半分鐘，所以這段文字幾乎一直出現，看不到速度。

- 速度數字現在一直顯示。rclone 在等雲端確認檔案時，速度改看最近約一分鐘的平均，不會突然掉到 0；只在比對檔案或建立資料夾時，維持上一次傳輸時的速度。
- 這兩種情況下，速度旁會出現一個小轉圈，代表 rclone 還在忙。滑鼠移過去會說明它在等什麼。
- 用一次真實的 Google Drive 上傳紀錄（1432 秒）重播：0.10.2 有 58% 的時間速度被文字取代；0.10.3 只剩約 7% 的時間顯示 0，都是超過一分鐘完全沒有新資料的時段。
- 剩餘時間在等雲端確認時也改用最近約一分鐘的平均，不再消失。

## 滑鼠提示涵蓋整個項目

原本說明只掛在「不用傳」「已略過」這類名稱的幾個字上，移到旁邊的數字不會出現。

- 傳輸卡片上每個統計項目，從名稱、數字，一直到下一個項目之前的空白，都會顯示說明；「詳細資料與紀錄」裡的統計也一樣。
- 傳輸選項視窗裡，說明涵蓋整列（名稱與輸入欄），不只左邊的名稱。

## Mac 版工具列維持原本的樣子

用 macOS 26 以後的 Xcode 或 Command Line Tools 直接從原始碼建置 0.10.2 時，新版 macOS 會在工具列每個按鈕外加上玻璃圓圈，和設計不同。GitHub 上發布的 0.10.2 由舊版工具建置，沒有這個問題。

- 建置時固定讓 App 以 macOS 15 的設計顯示，不論用哪一版 Apple 工具建置，工具列都沒有圓圈。
- 建置檢查會擋下不符合這個設定的 App，避免外觀悄悄改變。

## 其他

- Windows 安裝版加入「從 0.10.2 升級」的驗證。
- 專案介紹頁改寫：說明 Mac、Windows、Linux 都能使用，以及各系統的測試方式與穩定程度，並歡迎到 Issues 回報問題。

## 驗證

- 原生測試全部通過，包括「等雲端確認時改用一分鐘速度，不會突然變成 0」與「比對時維持上一次的速度」。
- 介面測試新增：速度旁的小轉圈與說明、每個統計項目的提示範圍首尾相連。
- 在開發版 App 中檢查正常傳輸、比對中、等雲端確認三種畫面；工具列在 macOS 27 上比對修正前後的截圖。
- Windows 與 Linux 版由 GitHub 的雲端測試機建置與自動測試；作者沒有在實體 Windows、Linux 電腦上測試這一版。
