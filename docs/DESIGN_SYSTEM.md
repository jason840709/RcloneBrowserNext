# Rclone Browser Next 介面設計規範

本文件定義 Mac 版介面的比例、字級、顏色、元件造型、間距與動畫規則。所有設計數值統一寫在 `WebSource/renderer/styles/tokens.css`，其他樣式檔只能引用變數；Mac 原生工具列（`Sources/Mac/MainToolbar.swift`）也採用相同的時間與動畫曲線。修改介面前請先閱讀本規範。

設計參考：macOS Finder、系統設定與 Apple Human Interface Guidelines。

## 1. 比例與列高

本文件的「點（pt）」即 macOS 長度單位。在介面大小 100% 時，CSS 的 `1px` 等於 macOS 的 `1pt`（WebKit 縮放比 1.0），設定中的 80%～125% 即對應實際縮放倍率。

對照 macOS Finder 清單規格：

| 項目 | 數值 |
|---|---|
| 清單文字 | 13 點 |
| 清單圖示（資料夾、檔案） | 16 點 |
| 清單列高 | 22 點（Finder 約 20 點，多留 2 點給勾選框） |
| 欄位標題 | 11 點 |
| 勾選框 | 14 點 |

實作注意：檔案清單使用虛擬捲動，`BrowserPane.tsx` 的 `fixedItemHeight` 必須與 `--row-h` 保持一致。窄窗格的容器查詢（container query）只能設在上方工具列（`.pane-header`），不可設在整個窗格，否則 WebKit 在非 100% 縮放時會算錯可視範圍導致捲動回彈。

## 2. 字級與文字顏色

每種用途對應唯一一組字級、字重與顏色，標題永遠不小於內容：

| 用途 | 變數 | 字級／字重 | 顏色 |
|---|---|---|---|
| 頁面大標題（傳輸、作業） | `--fs-display` | 17／700 | 主要文字 |
| 對話框標題 | `--fs-title` | 15／600 | 主要文字 |
| 區塊標題（設定分組） | `--fs-heading` | 13／600 | 主要文字 |
| 內文、清單、按鈕、表單值 | `--fs-body` | 13／400 | 主要文字 |
| 控制項下方說明、數據 | `--fs-callout` | 12／400 | 次要文字 |
| 小分組標籤、表格欄頭 | `--fs-label` | 11／600 或 500 | 次要文字 |
| 狀態列、時間 | `--fs-caption` | 11／400 | 次要文字 |
| 徽章數字 | `--fs-mini` | 10／600 | 依底色 |
| 路徑、指令、原始紀錄 | `--fs-mono` | 12，等寬字 | 次要文字 |

文字顏色分為四階：主要（`--label`）、次要（`--secondary`）、第三階（`--tertiary`，僅用於圖示與輔助資訊）與停用狀態。位置選單右側的連線方式標示（如「Mac 掛載」「SMB 直連」）使用 `--fs-callout`、字重 400 與 `--secondary` 次要文字色，不加外框或底色。

## 3. 配色與強調色

介面以中性灰階為主，低彩度的紫、綠、藍強調色只用在關鍵互動位置：

| 位置 | 變數 |
|---|---|
| 主要按鈕、勾選框、單選鈕、進度條、數量徽章、選單反白 | `--accent` |
| 資料夾圖示 | `--folder` |
| 作用中窗格的選取列 | `--selection` |
| 連結、文字按鈕、選取中分頁圖示、「來源」標籤、焦點外框 | `--accent-text` |

語意色（綠＝完成、紅＝錯誤、橘＝注意）只用於表示狀態。正常的等待階段（如比對檔案或等待雲端確認）照常顯示速度數字並轉為次要文字色，在後方加上小轉圈與滑鼠提示，不使用橘色以免被誤認為警告。滑鼠提示感應區須涵蓋整個統計項目（含名稱、數字與後方空白）。

原生工具列僅在「選取中頁面圖示」與「傳輸數量」使用強調色，視窗非作用中時跟隨系統轉為灰色。為維持 macOS 15 設計風格、避免 macOS 26 SDK 自動在工具列按鈕外加上玻璃圓圈，建置時於 `Scripts/common-mac.sh` 將主程式記錄的 SDK 版本固定為 15.0（使用 `RBN_DESIGN_SDK`），實際編譯仍使用已安裝的 SDK，並由 `verify-mac.sh` 檢查。

## 4. 元件造型

以形狀與凹凸深度區分元件功能：

| 元件 | 造型 |
|---|---|
| 按鈕、下拉選單按鈕 | 膠囊形、向外凸起（填色＋陰影），高 26 點 |
| 輸入框、搜尋框、網址列 | 6 點圓角矩形、向內凹陷（內陰影＋細框），高 24 點 |
| 分段控制、分頁切換 | 內凹膠囊軌道搭配單一凸起滑塊，未選取項無底色 |
| 圖示按鈕 | 平時無底色，滑鼠移過時顯示圓形底色 |
| 設定分組框 | 10 點圓角，標題置於框外上方 |
| 對話框 | 16 點圓角 |

位置選單、路徑與瀏覽按鈕合併為同一條網址列（左側為位置選單，以細線分隔右側路徑）。

## 5. 間距

以 4 點為基本單位：4、8、12、16、20、24、32（`--sp-1`～`--sp-8`）。設定區塊標題距離下方分組框 8 點、距離上方前一個分組框 21 點；對話框左右內距 20 點，底部按鈕間距 8 點。

## 6. 動畫

全 App 共用統一的動畫曲線與時間：進入使用減速曲線（`--ease-out`）或平滑曲線（`--ease-glide`），離開時間約為進入的 2/3；不回彈、不超調，且動畫期間不鎖定點擊操作。

| 互動 | 動畫效果 | 時間 |
|---|---|---|
| 滑鼠懸停、顏色過渡 | 漸變 | 120 毫秒 |
| 按下按鈕 | 縮小至 97%，放開還原 | 100～160 毫秒 |
| 分段控制、頂部頁面切換 | 滑塊平滑移動，文字與圖示同步變色 | 280 毫秒 |
| 切換傳輸方向 | 原來源側勾選欄收起淡出，新來源側展開浮現 | 約 450 毫秒 |
| 切換主頁面（檔案、傳輸、作業） | 新頁面依方向滑入 16 點並淡入（首次開啟不動） | 300 毫秒 |
| 切換設定／選項分頁 | 依方向滑入 14 點並淡入 | 300 毫秒 |
| 對話框 | 開啟：暗幕淡入、視窗上移 10 點並從 96% 放大；關閉：淡出微沉 | 開 260、關 180 毫秒 |
| 選單、彈出視窗 | 從按鈕處放大淡入；關閉淡出 | 開 200、關 120 毫秒 |
| 滑鼠提示（Tooltip） | 停留 0.4 秒後淡入 | 160 毫秒 |
| 展開進階選項／收合佇列 | 箭頭旋轉，內容高度展開或收起 | 240 毫秒 |
| 新增傳輸工作 | 從上方滑入 | 260 毫秒 |
| 浮動提示（如「設定已儲存」） | 從下方升起淡入，數秒後自動收起 | 260 毫秒 |
| 切換主題 | 全畫面交叉淡化 | 280 毫秒 |
| 進行中問題燈號 | 透明度在 100% 與 35% 間緩慢呼吸閃爍，結束後停止 | 週期 2.4 秒 |

當系統開啟「減少動態效果」時，所有位移與縮放改為 140 毫秒淡入淡出，問題燈號停止閃爍，僅保留讀取轉圈旋轉。

## 7. 視窗工具列與對話框關閉行為

- 雙擊 Mac 原生工具列空白處可放大視窗至螢幕可用範圍，再雙擊還原（對話框開啟期間停用）。
- 點擊對話框外的暗幕區域（含變暗的 Mac 工具列）即可關閉對話框，等同點擊「取消」。
- 若對話框內有尚未儲存的修改，點擊暗幕不會關閉，而是輕微晃動對話框提醒使用者。

## 8. 傳輸錯誤與問題燈號

每個工作卡片最多顯示一行錯誤摘要（一顆 7 點燈號＋一句白話標題），處理建議與 rclone 原始錯誤訊息則收合在「說明」中：

| 等級 | 觸發情境 | 燈號 | 預設狀態 |
|---|---|---|---|
| 注意 | rclone 會自動重試的狀況（雲端限流、網路瞬斷、伺服器暫時錯誤） | 橘燈（進行中慢閃） | 收起 |
| 需要處理 | 需使用者處理但工作仍可繼續（權限不足、檔名過長），或工作最終失敗 | 紅燈 | 收起 |
| 緊急 | 整個工作無法繼續（雲端空間已滿、本機磁碟已滿、登入過期） | 紅燈 | 自動展開一次 |

若工作在重試後最終成功完成，代表中途的暫時性錯誤已排除，畫面不再顯示燈號，錯誤次數也轉為一般次要文字色。
